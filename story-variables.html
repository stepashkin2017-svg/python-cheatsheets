Глава 2

Переменная — первая ячейка памяти

Костя рисует на доске большую коробку и подписывает её: ticket_price. Рядом кладёт карточку со словом «1990».

👨‍💻
Представьте коробку с наклейкой. Внутри — значение. Наклейка называется переменной, а содержимое — её значением. Изменилось значение — и вся программа работает с новыми данными.
ticket_price
1990
amount_adults
18
total
—

Байт оживляется: «Ага! Значит, я могу положить числа в коробки с именами, а потом сказать программе: умножь то, что лежит в первой коробке, на то, что во второй!»

Костя смеётся: «Именно так. Смотри, как это выглядит в коде».

# Кладём числа в переменные ticket_price = 1990 amount_adults = 18 # Считаем общую стоимость total = ticket_price * amount_adults # Печатаем результат print('Васечкин:') print(total)
Программа напечатает
Васечкин:
35820
Оператор присваивания. Знак = в Python — не «равно», а «положи в коробку». Читается справа налево: сначала посмотри, что справа, потом положи в переменную слева.

ticket_price = 1990 — «положи 1990 в переменную ticket_price».

Теперь, чтобы посчитать стоимость для другой группы, бухгалтеру достаточно поменять только значения переменных: ticket_price и amount_adults. Сам код трогать не нужно.

Запомни из главы 2

  • Переменная — это элемент данных, у которого есть собственное имя.
  • Значение в переменной можно менять.
  • Создание переменной состоит из двух шагов: придумать имя и задать значение.
  • = — оператор присваивания, а не «равно».
Глава 3

Как назвать переменную

Байт уже готов назвать переменные как попало: a, x, d1. Костя качает головой: «Стоп. Имя переменной — это важная часть кода. По нему другой программист должен понять, что внутри».

👨‍💻
Вот три правила, которые нельзя нарушать. Запишите их в блокнот.
# 1. Можно использовать буквы, цифры и знак _ ticket_price = 1990 amount_1 = 18 # 2. Имя начинается с буквы или _ _ticket = 1990 # ok 1ticket = 1990 # ошибка! # 3. Нельзя занимать имена команд языка # print, input, int, str, if, for, while — зарезервированы

Тут Байт замечает, что не все имена одинаково хороши. Костя показывает таблицу из проектной документации.

Неудачное имя

Совет от Кости. Пишите имена так, будто через месяц код будет читать другой человек. Если бы вы сами, открыв файл, сразу поняли, что лежит в переменной — значит, вы назвали её правильно.

Запомни из главы 3

  • В имени можно использовать буквы, цифры, подчёркивания.
  • Первым символом должна быть буква или _.
  • Имя не должно совпадать с командами языка (print, input, int…).
  • Хорошее имя объясняет, что лежит внутри: ticket_price, а не a.
Глава 4

Три типа данных

Байт замечает, что в переменных могут лежать очень разные значения. «Одни в кавычках, другие без… Это что-то меняет?» — спрашивает он.

👨‍💻
Ещё как! Каждое значение имеет тип. Сегодня мы работаем с тремя: целые числа, десятичные дроби и строки.
int
42
целое число
float
3.14
десятичная дробь
str
"Васечкин"
строка, текст

Костя объясняет: «Разные типы — для разных задач. Числа можно складывать и умножать. Строки — соединять. Но смешивать их без подготовки нельзя».

# Примеры с числами ticket_price = 1990 # int discount = 0.15 # float total = ticket_price * 18 print(total) # 35820 # Пример со строкой guide = 'Васечкин' # str print('Экскурсовод:', guide)
Как отличить строку? Она всегда в кавычках — одинарных или двойных. 'Васечкин' и "Васечкин" — одно и то же. Число без кавычек — это число. Число в кавычках — уже строка!

Запомни из главы 4

  • Мы работаем с тремя типами: int (целые), float (дроби), str (строки).
  • Числа пишутся без кавычек, строки — в кавычках.
  • С числами можно считать, со строками — соединять.
  • Тип определяет, что можно делать со значением.

Добрый день, Константин!

Недавно ваши стажёры помогли мне с программой. Я могла менять значения переменных и использовать её для разных данных.

Но на прошлой неделе программой воспользовался новый сотрудник и, кроме значений, случайно изменил сам код. Программа перестала работать.

Байт чешет затылок: «И как это — данные сами вводятся?» Костя улыбается и открывает новую страницу блокнота.

👨‍💻
Есть в Python волшебная функция — input(). Она останавливает программу, задаёт вопрос пользователю и ждёт, пока он что-нибудь напечатает. То, что напечатано, попадает в переменную.
# Программа задаёт вопросы и ждёт ответа guide = input('Введите фамилию экскурсовода: ') city = input('Введите город: ') print('Директор филиала в г.', city, '-', guide)
Что увидит пользователь
Введите фамилию экскурсовода: Солнцев
Введите город: Тула
Директор филиала в г. Тула - Солнцев
Как работает input() по шагам:
  1. Python видит команду input('...').
  2. Показывает надпись в скобках на экране.
  3. Останавливается и ждёт, пока пользователь что-то напечатает и нажмёт Enter.
  4. То, что напечатано, кладёт в переменную слева от знака =.

Теперь программа сама спрашивает данные. Бухгалтеру не нужно менять код — достаточно ответить на вопросы!

Запомни из главы 5

  • input() — функция для ввода данных с клавиатуры.
  • Пока пользователь не нажмёт Enter, программа ждёт.
  • Текст в скобках — это подсказка, что спросить у пользователя.
  • Ответ попадает в переменную слева от =.
Глава 6

Ловушка: input() возвращает строку!

Байт с гордостью пишет программу для турфирмы. Он использует input() и пробует прибавить к цене стоимость дополнительных услуг.

add_services = input('Стоимость дополнительных услуг: ') total = 2500 + add_services print('Общая стоимость:', total)

Он запускает программу и… видит вот это:

Ошибка!
Стоимость дополнительных услуг: 300

[2:0] unsupported operand type(s) for Add: 'int' and 'str'
Что случилось? Python не умеет складывать число 2500 и строку "300". Ведь input() всегда возвращает строку — даже если пользователь напечатал число! unsupported operand type(s) for Add: 'int' and 'str'

«Хм, — задумывается Байт. — То есть, чтобы работать с этим числом, мне нужно превратить строку в число?» Костя кивает: «Именно. И для этого есть функция int()».

👨‍💻
int() превращает строку в целое число. Есть ещё str() — она делает обратное: превращает число в строку. Это два ключевых инструмента для смены типа.

Байт исправляет программу — теперь можно сразу превратить ответ пользователя в число:

# int() превращает ответ input() в число add_services = int( input('Стоимость доп. услуг: ') ) total = 2500 + add_services print('Общая стоимость:', total)
Всё работает!
Стоимость доп. услуг: 300
Общая стоимость: 2800
Простое правило. Если программа должна считать с числом, которое ввёл пользователь, — оборачивайте input() в int():

age = int(input('Сколько тебе лет? '))

Если же число, наоборот, нужно приклеить к тексту — используйте str():

print('Ответ: ' + str(age))

Запомни из главы 6

  • input() всегда возвращает строку, даже если пользователь напечатал число.
  • Строку нельзя складывать с числом — это ошибка.
  • int() превращает строку в целое число, чтобы с ним можно было считать.
  • str() — наоборот, превращает число в строку, чтобы приклеить его к тексту.
