1. Открытие текстового файла

Базовый синтаксис open()

Функция open() открывает файл и возвращает файловый объект.

file = open("data.txt", "r", encoding="utf-8")

print(file.read())

file.close()
Важно: после ручного open() файл нужно закрыть методом close().

Рекомендуемый способ — with

Конструкция with автоматически закрывает файл после завершения блока.

with open("data.txt", "r", encoding="utf-8") as file:
    text = file.read()

print(text)
В большинстве обычных задач используйте именно with open(...).

Создание нового файла

Режим "w" создаёт файл, если его ещё нет.

with open("new.txt", "w", encoding="utf-8") as file:
    file.write("Привет, Python!")
Осторожно: режим w очищает существующий файл.

Проверка существования файла

Для проверки удобно использовать Path из модуля pathlib.

from pathlib import Path

path = Path("data.txt")

if path.exists():
    print("Файл существует")
else:
    print("Файла нет")

3. Чтение текстового файла

read() — весь файл

Возвращает всё содержимое файла одной строкой.

with open("data.txt", encoding="utf-8") as file:
    text = file.read()

print(text)

read(n) — несколько символов

Можно прочитать указанное количество символов.

with open("data.txt", encoding="utf-8") as file:
    text = file.read(10)

print(text)

readline() — одна строка

Каждый вызов читает следующую строку.

with open("data.txt", encoding="utf-8") as file:
    line1 = file.readline()
    line2 = file.readline()

print(line1)
print(line2)

readlines() — список строк

Возвращает строки файла в виде списка.

with open("data.txt", encoding="utf-8") as file:
    lines = file.readlines()

print(lines)
Обычно каждая строка в списке сохраняет символ перевода строки \n.

Чтение файла циклом

Файловый объект можно перебирать построчно.

with open("data.txt", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
Такой способ удобен для больших файлов: не обязательно загружать весь файл в память.

Количество строк

with open("data.txt", encoding="utf-8") as file:
    count = 0

    for line in file:
        count += 1

print("Строк:", count)

4. Запись в текстовый файл

write() — записать строку

with open("result.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка")
write() не добавляет \n автоматически.

Несколько строк

with open("result.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка\n")
    file.write("Вторая строка\n")
    file.write("Третья строка\n")

writelines()

Записывает последовательность строк. Переводы строк нужно добавить самостоятельно.

lines = [
    "Анна\n",
    "Борис\n",
    "Виктор\n"
]

with open("names.txt", "w", encoding="utf-8") as file:
    file.writelines(lines)

Добавление через "a"

with open("notes.txt", "a", encoding="utf-8") as file:
    file.write("Новая заметка\n")
Режим a сохраняет старое содержимое и дописывает новые данные в конец.

Запись числа

write() принимает строку, поэтому число нужно преобразовать.

age = 15

with open("age.txt", "w", encoding="utf-8") as file:
    file.write(str(age))

Запись с f-строкой

name = "Анна"
score = 95

with open("result.txt", "w", encoding="utf-8") as file:
    file.write(f"Ученик: {name}\n")
    file.write(f"Баллы: {score}\n")

5. Обработка строк файла

strip() — убрать пробелы и \n

with open("names.txt", encoding="utf-8") as file:
    for line in file:
        name = line.strip()
        print(name)

split() — разделить строку

text = "Иван;15;Москва"

parts = text.split(";")

print(parts)
# ['Иван', '15', 'Москва']

splitlines() — строки из текста

text = """Первая
Вторая
Третья"""

lines = text.splitlines()

print(lines)

Фильтрация строк

with open("numbers.txt", encoding="utf-8") as file:
    for line in file:
        number = int(line.strip())

        if number > 10:
            print(number)

Подсчёт слов

with open("text.txt", encoding="utf-8") as file:
    text = file.read()

words = text.split()

print("Слов:", len(words))

Поиск текста

with open("data.txt", encoding="utf-8") as file:
    for line in file:
        if "Python" in line:
            print(line.strip())

6. Кодировка текста

UTF-8

Для русскоязычных текстов удобно явно указывать encoding="utf-8".

with open("text.txt", "r", encoding="utf-8") as file:
    text = file.read()

print(text)

Запись UTF-8

with open("text.txt", "w", encoding="utf-8") as file:
    file.write("Привет! Это русский текст.")
Явное указание кодировки делает программу более предсказуемой на разных системах.

Ошибка кодировки

При несовместимой кодировке может возникнуть UnicodeDecodeError.

try:
    with open("text.txt", encoding="ascii") as file:
        text = file.read()
except UnicodeDecodeError:
    print("Проблема с кодировкой")

7. Пути к файлам и pathlib

Текущая папка

from pathlib import Path

path = Path("data.txt")

print(path)
print(path.exists())

Вложенная папка

from pathlib import Path

path = Path("data") / "notes" / "text.txt"

with open(path, encoding="utf-8") as file:
    print(file.read())

Запись через Path.write_text()

from pathlib import Path

path = Path("hello.txt")

path.write_text(
    "Привет, Python!",
    encoding="utf-8"
)

Чтение через Path.read_text()

from pathlib import Path

path = Path("hello.txt")

text = path.read_text(encoding="utf-8")

print(text)

Поиск TXT-файлов

from pathlib import Path

folder = Path("data")

for path in folder.glob("*.txt"):
    print(path)

Размер файла

from pathlib import Path

path = Path("data.txt")

print("Размер:", path.stat().st_size, "байт")

8. Обработка ошибок

Файл не найден

try:
    with open("data.txt", encoding="utf-8") as file:
        text = file.read()
except FileNotFoundError:
    print("Файл не найден")

Несколько исключений

try:
    with open("data.txt", encoding="utf-8") as file:
        text = file.read()
except FileNotFoundError:
    print("Нет файла")
except UnicodeDecodeError:
    print("Ошибка кодировки")

Полный пример с else и finally

try:
    with open("data.txt", encoding="utf-8") as file:
        text = file.read()
except FileNotFoundError:
    print("Файл не найден")
else:
    print("Файл успешно прочитан")
finally:
    print("Операция завершена")

9. Работа с JSON-файлами

Что такое JSON?

JSON — текстовый формат хранения структурированных данных. В Python для работы с ним используется стандартный модуль json.

import json

data = {
    "name": "Анна",
    "age": 15,
    "city": "Москва"
}

print(data)
JSON-файл обычно имеет расширение .json.

Запись объекта в JSON — json.dump()

dump() записывает Python-объект непосредственно в открытый файл.

import json

data = {
    "name": "Анна",
    "age": 15,
    "city": "Москва"
}

with open("user.json", "w", encoding="utf-8") as file:
    json.dump(data, file, ensure_ascii=False, indent=4)
ensure_ascii=False сохраняет русские буквы, а indent=4 делает файл удобным для чтения.

Чтение JSON-файла — json.load()

load() читает JSON из открытого файла и превращает его в объект Python.

import json

with open("user.json", "r", encoding="utf-8") as file:
    data = json.load(file)

print(data)
print(data["name"])
print(data["age"])

json.dumps() — объект → строка

Метод dumps() преобразует Python-объект в JSON-строку.

import json

data = {
    "name": "Анна",
    "age": 15
}

text = json.dumps(
    data,
    ensure_ascii=False,
    indent=4
)

print(text)

json.loads() — строка → объект

loads() преобразует JSON-строку обратно в объект Python.

import json

text = '{"name": "Анна", "age": 15}'

data = json.loads(text)

print(data)
print(data["name"])

Список объектов в JSON

JSON удобно использовать для хранения коллекций записей.

import json

users = [
    {"name": "Анна", "age": 15},
    {"name": "Иван", "age": 16},
    {"name": "Олег", "age": 14}
]

with open("users.json", "w", encoding="utf-8") as file:
    json.dump(
        users,
        file,
        ensure_ascii=False,
        indent=4
    )

Чтение списка из JSON

import json

with open("users.json", encoding="utf-8") as file:
    users = json.load(file)

for user in users:
    print(user["name"], user["age"])

Изменение JSON-данных

import json

with open("user.json", encoding="utf-8") as file:
    user = json.load(file)

user["age"] += 1

with open("user.json", "w", encoding="utf-8") as file:
    json.dump(
        user,
        file,
        ensure_ascii=False,
        indent=4
    )

Обработка ошибки JSON

import json

try:
    with open("data.json", encoding="utf-8") as file:
        data = json.load(file)
except FileNotFoundError:
    print("JSON-файл не найден")
except json.JSONDecodeError:
    print("Некорректный JSON")

11. Мини-проект: обработка списка чисел

Прочитаем числа из numbers.txt, найдём сумму и среднее значение, затем сохраним результат.

# numbers.txt:
# 10
# 20
# 30
# 40

with open("numbers.txt", encoding="utf-8") as file:
    numbers = []

    for line in file:
        number = int(line.strip())
        numbers.append(number)

total = sum(numbers)
average = total / len(numbers)

with open("result.txt", "w", encoding="utf-8") as file:
    file.write(f"Сумма: {total}\n")
    file.write(f"Среднее: {average:.2f}\n")

print("Результат сохранён в result.txt")

12. Мини-проект: текстовый журнал

Добавляем события в файл, не удаляя предыдущие записи.

from datetime import datetime

message = input("Введите сообщение: ")

now = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

with open("journal.txt", "a", encoding="utf-8") as file:
    file.write(f"[{now}] {message}\n")

print("Запись добавлена.")
Режим a особенно удобен для журналов, логов и истории действий.
