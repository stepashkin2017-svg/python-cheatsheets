Модуль turtle

От линий и фигур до анимации и обработки событий. Примеры запускаются на вашем компьютере (нужен установленный tkinter, он есть в стандартной сборке Python).

Старт

Черепаха — это курсор, который двигается по холсту и рисует за собой линию. Есть два стиля: функции модуля и объекты.

Минимальная программа

import turtle

t = turtle.Turtle()    # создаём черепаху
t.forward(100)         # вперёд на 100 пикселей
turtle.done()          # окно остаётся открытым

Объектный стиль

Рекомендуется: отдельный объект экрана и одна или несколько черепах.

import turtle
screen = turtle.Screen()
t = turtle.Turtle()
t.fd(80)
screen.mainloop()

Процедурный стиль

Команды модуля работают с «безымянной» черепахой.

from turtle import *
forward(100)
left(90)
forward(50)
done()

Завершение

turtle.done()           # ждать закрытия окна
screen.mainloop()       # то же для объекта экрана
screen.exitonclick()    # закрыть по клику
screen.bye()            # закрыть окно программно

Движение и положение

Начало координат — центр окна (0, 0). Ось X вправо, Y вверх. Угол 0° — направо, положительный поворот — против часовой стрелки.

Вперёд, назад, повороты

t.forward(100)   # fd — вперёд
t.backward(50)   # bk — назад
t.left(90)       # lt — влево на 90°
t.right(45)      # rt — вправо на 45°

Перейти в точку

t.goto(100, 50)    # в координаты (x, y)
t.setx(-30)        # только x
t.sety(40)         # только y
t.home()           # в (0, 0), курс вправо

Направление

t.setheading(90)   # seth — смотреть вверх
t.heading()        # текущий угол
t.towards(100, 0)  # угол на точку

Где я

t.pos()            # (x, y)
t.xcor(), t.ycor() # по отдельности
t.distance(0, 0)   # расстояние до точки
t.distance(other)  # до другой черепахи

Отмена и очистка

t.undo()      # отменить последнее действие
t.clear()     # стереть рисунок, остаться на месте
t.reset()     # стереть и вернуть всё по умолчанию
screen.clear()   # очистить весь экран

Скорость

От 1 (медленно) до 10 (быстро), 0 — без анимации.

t.speed(0)         # мгновенно
t.speed("fast")    # слова: slowest, slow, normal, fast, fastest
t.speed()          # узнать текущую

Перо и цвет

Поднять и опустить перо

Без опущенного пера черепаха двигается, но не рисует.

t.penup()      # pu — не рисовать
t.goto(-100, 0)
t.pendown()    # pd — рисовать
t.isdown()     # True/False

Толщина линии

t.pensize(5)     # то же что width(5)
t.pensize()      # узнать

Цвета

Имя, hex-строка или RGB-кортеж. Для чисел 0–255 включите colormode(255).

t.pencolor("red")          # цвет линии
t.fillcolor("#ffcc00")     # цвет заливки
t.color("blue", "yellow")  # линия, заливка
turtle.colormode(255)
t.pencolor((30, 144, 255))
screen.bgcolor("black")    # фон

Заливка фигуры

Всё, что нарисовано между begin_fill и end_fill, заливается.

t.color("green", "lightgreen")
t.begin_fill()
for _ in range(3):
    t.fd(100)
    t.lt(120)
t.end_fill()

Видимость черепахи

t.hideturtle()   # ht — спрятать курсор
t.showturtle()   # st — показать
t.isvisible()    # True/False

Случайные цвета

import random
turtle.colormode(255)
t.pencolor(random.randint(0, 255),
           random.randint(0, 255),
           random.randint(0, 255))

Графические примитивы и текст

Отрезок и ломаная

t.goto(0, 0)
t.pendown()
t.goto(100, 100)   # линия в точку
t.goto(150, 0)     # продолжение

Квадрат и многоугольник

Для правильного n-угольника угол поворота равен 360 / n.

for _ in range(4):        # квадрат
    t.fd(100); t.lt(90)

n = 6                     # шестиугольник
for _ in range(n):
    t.fd(60); t.lt(360 / n)

Звезда

for _ in range(5):
    t.fd(150)
    t.rt(144)    # пятиконечная
# 8-конечная: угол 135, 8 повторов

Окружность, дуга, многоугольник

circle(радиус, угол, шаги). Радиус положительный — центр слева от черепахи.

t.circle(50)           # окружность
t.circle(50, 180)      # полуокружность
t.circle(50, steps=5)  # пятиугольник
t.circle(-50)          # в другую сторону

Точка

t.dot(20, "red")   # круг диаметром 20
for x in range(-100, 101, 50):
    t.penup(); t.goto(x, 0)
    t.dot(15, "orange")

Штамп

Оставляет отпечаток формы черепахи на холсте.

t.shape("turtle")
t.stamp()          # вернёт id отпечатка
t.fd(40)
t.clearstamps()    # стереть все штампы

Спираль

t.speed(0)
for i in range(80):
    t.fd(i * 3)
    t.rt(91)

Текст

write(текст, move, align, font). Выравнивание: "left", "center", "right".

t.penup(); t.goto(0, 100)
t.write("Привет, turtle!", align="center",
        font=("Arial", 18, "bold"))

Экран и анимация

Окно

screen = turtle.Screen()
screen.setup(800, 600)        # размер окна
screen.title("Мой рисунок")
screen.bgcolor("#101820")
screen.bgpic("map.gif")       # фоновая картинка (gif)

Свои координаты

Задаёт область: левый нижний и правый верхний углы.

screen.setworldcoordinates(0, 0, 100, 100)
# теперь (0,0) — левый нижний угол

Ввод через диалог

name = screen.textinput("Имя", "Как вас зовут?")
n = screen.numinput("Углы", "Сколько?", 5,
                    minval=3, maxval=20)

Быстрая отрисовка: tracer и update

tracer(0) отключает автоперерисовку, update() показывает кадр целиком. Так делают плавную анимацию.

screen.tracer(0)
# ... много команд рисования ...
screen.update()

Размеры окна

screen.window_width()    # ширина
screen.window_height()   # высота

Анимация по таймеру

ontimer(функция, мс) вызывает функцию через заданное время. Если вызвать себя снова — получится цикл кадров.

def tick():
    t.fd(3)
    t.rt(2)
    screen.update()
    screen.ontimer(tick, 30)   # ~33 кадра/с
screen.tracer(0)
tick()
screen.mainloop()

Обработка событий

Сначала включите приём событий: screen.listen(). Обработчик передаётся без скобок. Цикл событий запускает mainloop().

Нажатие клавиши

onkey сработает при отпускании, onkeypress — при нажатии (и повторяется при удержании).

def go_up():
    t.sety(t.ycor() + 20)

screen.listen()
screen.onkey(go_up, "Up")
screen.onkeypress(go_up, "w")
screen.mainloop()

Имена клавиш

"Up" "Down" "Left" "Right"
"space" "Return" "Escape" "BackSpace"
"a" "b" … "1" "2" …      # символы
"F1" … "F12"
screen.onkeyrelease(f, "a")  # отпускание

Клик по экрану

Обработчик получает координаты x, y. Третий аргумент btn: 1 — левая, 2 — средняя, 3 — правая кнопка.

def draw(x, y):
    t.goto(x, y)

screen.onscreenclick(draw)
screen.onscreenclick(lambda x, y: t.dot(10, "red"), 3)

Клик по черепахе

def hit(x, y):
    t.color("red")

t.onclick(hit)

Перетаскивание

Классический приём: goto как обработчик.

t.ondrag(t.goto)    # тащим черепаху мышью
t.onrelease(lambda x, y: print("отпущена"))

Таймер

screen.ontimer(f, 1000)   # один раз через 1 с
# периодически — вызовите ontimer внутри f

Выход по клавише

screen.listen()
screen.onkey(screen.bye, "Escape")

Состояние через global

Обработчики не получают аргументов клавиш, поэтому общие данные хранят в переменных.

score = 0
def add():
    global score
    score += 1
    t.clear()
    t.write(score, font=("Arial", 20, "normal"))
screen.onkey(add, "space")

Встроенные формы: "arrow", "turtle", "circle", "square", "triangle", "classic".

Изображение в формате .gif или многоугольник по точкам.

Мини-проекты

Рисовалка: мышь и клавиши

Тащим черепаху мышью, цвет и толщина меняются клавишами.

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
t = turtle.Turtle()
t.speed(0); t.pensize(3)

colors = {"r": "red", "g": "green", "b": "blue", "k": "black"}

def set_color(c):
    return lambda: t.pencolor(c)         # фабрика обработчиков

def thicker(): t.pensize(t.pensize() + 1)
def thinner(): t.pensize(max(1, t.pensize() - 1))
def clear():   t.clear()

t.ondrag(t.goto)                         # рисуем перетаскиванием
for key, c in colors.items():
    screen.onkey(set_color(c), key)
screen.onkey(thicker, "plus")
screen.onkey(thinner, "minus")
screen.onkey(clear, "c")
screen.listen()
screen.mainloop()

Игра: поймай цель

Игрок движется стрелками, цель появляется в случайном месте, очки растут при касании.

import turtle, random

screen = turtle.Screen()
screen.setup(600, 600); screen.tracer(0)

player = turtle.Turtle("turtle"); player.penup(); player.color("green")
target = turtle.Turtle("circle"); target.penup(); target.color("red")
target.goto(random.randint(-250, 250), random.randint(-250, 250))
pen = turtle.Turtle(visible=False); pen.penup(); pen.goto(0, 260)

score = 0
def show():
    pen.clear()
    pen.write(f"Очки: {score}", align="center", font=("Arial", 16, "bold"))

def move(dx, dy):
    return lambda: player.goto(player.xcor() + dx, player.ycor() + dy)

screen.listen()
screen.onkeypress(move(0, 20), "Up")
screen.onkeypress(move(0, -20), "Down")
screen.onkeypress(move(-20, 0), "Left")
screen.onkeypress(move(20, 0), "Right")

def loop():
    global score
    if player.distance(target) < 20:        # столкновение
        score += 1
        target.goto(random.randint(-250, 250), random.randint(-250, 250))
        show()
    screen.update()
    screen.ontimer(loop, 30)

show(); loop()
screen.mainloop()

Часы: анимация по таймеру

import turtle, time

screen = turtle.Screen(); screen.tracer(0); screen.bgcolor("black")
t = turtle.Turtle(visible=False); t.penup(); t.color("white")

def tick():
    t.clear()
    t.write(time.strftime("%H:%M:%S"), align="center", font=("Courier", 40, "bold"))
    screen.update()
    screen.ontimer(tick, 1000)

tick()
screen.mainloop()
Совет: для быстрых рисунков ставьте speed(0) или tracer(0) и вызывайте update() в конце.
