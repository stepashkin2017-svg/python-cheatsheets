1. Что такое Kivy?

Kivy

Kivy — Python-фреймворк для создания приложений с графическим интерфейсом, включая приложения для Android, iOS и настольных платформ.

from kivy.app import App

class MyApp(App):
    pass

MyApp().run()
Официальная документация описывает Kivy как кроссплатформенный framework для приложений с интерфейсом и touch-взаимодействием.

Установка

python -m pip install "kivy[base]"

Для учебного проекта можно создать виртуальное окружение:

python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

2. Пустое приложение

Минимальный main.py

from kivy.app import App

class MyApp(App):

    def build(self):
        return None

MyApp().run()

Окно с Label

from kivy.app import App
from kivy.uix.label import Label

class MyApp(App):

    def build(self):
        return Label(text="Привет, Kivy!")

MyApp().run()

Класс приложения

Обычно создают собственный класс, наследующий App, а интерфейс возвращают из build().

class MyApp(App):

    def build(self):
        return Label(
            text="Моё приложение"
        )
App.run() запускает жизненный цикл приложения и главный цикл Kivy.

Точка входа

if __name__ == "__main__":
    MyApp().run()

4. Разметка интерфейса — Layouts

BoxLayout

Располагает дочерние виджеты последовательно по вертикали или горизонтали.

from kivy.uix.boxlayout import BoxLayout

layout = BoxLayout(
    orientation="vertical",
    spacing=10,
    padding=10
)

Добавление виджетов

layout.add_widget(
    Label(text="Имя")
)

layout.add_widget(
    Button(text="OK")
)

GridLayout

from kivy.uix.gridlayout import GridLayout

layout = GridLayout(
    cols=2,
    spacing=5
)

layout.add_widget(Label(text="Имя"))
layout.add_widget(TextInput())

AnchorLayout

from kivy.uix.anchorlayout import AnchorLayout

layout = AnchorLayout(
    anchor_x="center",
    anchor_y="center"
)

FloatLayout

from kivy.uix.floatlayout import FloatLayout

layout = FloatLayout()

button = Button(
    text="OK",
    size_hint=(.4, .2),
    pos_hint={"center_x": .5,
              "center_y": .5}
)

layout.add_widget(button)

Размер и позиция

widget.size = (200, 80)
widget.pos = (20, 30)

# относительные значения:
widget.size_hint = (.5, .2)
widget.pos_hint = {
    "center_x": .5
}

5. События и обработчики

Button → on_press

def hello(instance):
    print("Привет!")

button.bind(
    on_press=hello
)

Button → on_release

button.bind(
    on_release=lambda x:
        print("Нажатие завершено")
)

Полный пример

from kivy.app import App
from kivy.uix.button import Button

class MyApp(App):

    def build(self):
        button = Button(text="Нажми")

        button.bind(
            on_press=self.clicked
        )

        return button

    def clicked(self, instance):
        instance.text = "Готово!"

MyApp().run()

Событие TextInput

def changed(instance, value):
    print("Текст:", value)

text_input.bind(
    text=changed
)
У Kivy свойства могут быть связаны с callback-функциями через bind().

6. Свойства Kivy

StringProperty

from kivy.properties import StringProperty

class MyWidget(Widget):
    title = StringProperty("Hello")

widget.title = "Привет"

NumericProperty

from kivy.properties import NumericProperty

class Counter(Widget):
    value = NumericProperty(0)

counter.value += 1

BooleanProperty

from kivy.properties import BooleanProperty

class MyWidget(Widget):
    enabled = BooleanProperty(True)

ObjectProperty

from kivy.properties import ObjectProperty

class MainWidget(Widget):
    button = ObjectProperty(None)

Связь свойства

def changed(instance, value):
    print(value)

counter.bind(
    value=changed
)

counter.value = 10

Зачем нужны Properties?

Они позволяют Kivy отслеживать изменения данных и связывать их с интерфейсом, в том числе с KV-разметкой.

value = NumericProperty(0)

# изменение:
value = 10

# связанные элементы
# могут отреагировать автоматически

7. KV-язык — описание интерфейса отдельно от Python

main.py

from kivy.app import App
from kivy.uix.boxlayout import BoxLayout

class MainLayout(BoxLayout):
    pass

class MyApp(App):
    pass

MyApp().run()

my.kv

<MainLayout>:
    orientation: "vertical"

    Label:
        text: "Привет, Kivy!"

    Button:
        text: "OK"
Если класс приложения называется MyApp, Kivy может автоматически искать файл my.kv.

on_release в KV

<MainLayout>:
    Button:
        text: "Нажми"
        on_release:
            app.button_clicked()

Метод App

class MyApp(App):

    def button_clicked(self):
        print("Кнопка нажата")

id в KV

<MainLayout>:
    TextInput:
        id: name_input

    Button:
        text: "Привет"
        on_release:
            print(name_input.text)

Значение свойства в KV

<Label>:
    font_size: "24sp"
    color: 0.1, 0.5, 0.8, 1
KV особенно удобен для отделения построения интерфейса от логики Python.

10. Работа с файлами приложения

Чтение файла

from pathlib import Path

path = Path("data.txt")

if path.exists():
    text = path.read_text(
        encoding="utf-8"
    )
    print(text)

Запись файла

from pathlib import Path

Path("data.txt").write_text(
    "Привет!",

)

Хранение данных

import json

data = {
    "theme": "dark",
    "volume": 80
}

with open("settings.json", "w",
          encoding="utf-8") as file:
    json.dump(
        data, file,
        ensure_ascii=False,
        indent=4
    )

Важно для Android

Для мобильного приложения пути и доступ к файлам нужно проектировать с учётом Android-модели хранения и разрешений. Не стоит бездумно использовать произвольные абсолютные пути вроде C:\....

12. Сборка Kivy-приложения в APK

Что используется?

Buildozer автоматизирует упаковку приложения, а Android-сборка использует toolchain python-for-android. В официальной документации Buildozer для Android описана сборка через buildozer.spec.

Python
   ↓
Kivy
   ↓
Buildozer
   ↓
python-for-android
   ↓
Android SDK / NDK
   ↓
APK / AAB
Buildozer для Android запускается на Linux или macOS; на Windows обычно используют WSL2 с Linux.

13. Windows: подготовка WSL2

Почему WSL2?

Актуальная документация Buildozer указывает, что Windows требует WSL для использования Linux-инструментария Android-сборки. Для проекта рекомендуется работать внутри файловой системы WSL, а не собирать непосредственно из /mnt/c.

# в Ubuntu / WSL:
pwd

# пример каталога проекта:
~/projects/my_kivy_app

Установка WSL

# PowerShell от администратора
wsl --install

После установки запустите Ubuntu и создайте проект внутри Linux-файловой системы.

Ubuntu — системные пакеты

sudo apt update

sudo apt install -y \
git zip unzip openjdk-17-jdk \
python3-pip python3-virtualenv \
autoconf libtool pkg-config \
zlib1g-dev libncurses5-dev \
libncursesw5-dev libtinfo6 \
cmake libffi-dev libssl-dev \
automake autopoint gettext
Набор пакетов зависит от версии Ubuntu; актуальная документация Buildozer содержит отдельные инструкции для Ubuntu 22.04, 24.04 и 26.04.

Установка Buildozer

python3 -m pip install --user \
--upgrade buildozer

Для конкретной версии Python/Cython следует ориентироваться на текущую инструкцию Buildozer.

14. Создание buildozer.spec

cd ~/projects/my_kivy_app

buildozer init

В папке проекта появится файл buildozer.spec. Его нужно отредактировать перед первой сборкой.

15. Основные параметры buildozer.spec

[app]

title = My Kivy App
package.name = mykivyapp
package.domain = org.example

source.dir = .
source.include_exts = py,kv,png,jpg,jpeg,json

version = 1.0

requirements = python3,kivy

orientation = portrait

fullscreen = 0

# иконка:
# icon.filename = %(source.dir)s/assets/icon.png
ПараметрНазначение
titleНазвание приложения
package.nameИмя Android-пакета
package.domainДоменная часть идентификатора
source.dirПапка исходников
source.include_extsРасширения файлов, включаемых в пакет
requirementsPython-зависимости приложения
orientationОриентация экрана
versionВерсия приложения
icon.filenameПуть к иконке
Buildozer использует requirements для определения зависимостей. Для пакетов с нативными расширениями может потребоваться соответствующий recipe python-for-android.

16. Версия приложения

Buildozer умеет извлекать версию из main.py, если в нём есть переменная __version__.

__version__ = "1.0.0"

from kivy.app import App

class MyApp(App):
    pass

MyApp().run()

17. Первая debug-сборка APK

cd ~/projects/my_kivy_app

buildozer -v android debug

При первой сборке Buildozer скачивает необходимые Android-инструменты и зависимости, поэтому процесс может быть долгим.

После успешной сборки результат появляется в каталоге bin/; в зависимости от конфигурации это может быть APK или AAB.

18. Установка APK на телефон

Через ADB

adb install -r \
bin/mykivyapp-1.0-arm64-v8a-debug.apk

Конкретное имя файла зависит от результата сборки.

Через Buildozer

buildozer android deploy run logcat

Команда позволяет развернуть приложение на подключённом устройстве, запустить его и получить logcat после предварительной компиляции.

APK вручную

Можно скопировать APK из bin/ на Android-смартфон и установить его обычным способом, если настройки безопасности устройства это позволяют.

ADB-проверка устройства

adb devices
Если устройство не отображается, сначала проверьте USB debugging и драйверы/ADB.

19. Release-сборка

buildozer android release

Release-сборка предназначена для подготовки релизного пакета. Для публикации в магазинах потребуется корректно настроенная подпись и соответствующая конфигурация Android-пакета.

Не путайте debug APK и релизный пакет: debug удобен для разработки и тестирования; публикационный пакет требует дополнительных шагов с подписью и требованиями магазина.

20. Зависимости в APK

[app]

requirements = python3,kivy,requests

Если приложение использует библиотеку, она должна быть указана в requirements, если она должна попасть в Android-пакет.

# пример Python:
import requests

response = requests.get(
    "https://example.com"
)
Не каждая Python-библиотека автоматически совместима с Android. Пакеты с нативными расширениями могут требовать recipe python-for-android.

21. Типичные проблемы при сборке

Buildozer не запускается в Windows

Проверьте, что используется WSL2 и Linux-среда для Android-сборки.

wsl --status

Сборка очень медленная

Первая сборка скачивает SDK, NDK и другие компоненты. При WSL рекомендуется держать проект в файловой системе Linux, например в ~/projects/, а не в /mnt/c/.

Модуль не собирается

Проверьте requirements и наличие поддержки нужного пакета в python-for-android.

requirements = python3,kivy,my_package

APK не содержит картинку

Проверьте расширения в source.include_exts.

source.include_exts = py,kv,png,jpg,jpeg

Ошибка AIDL / Android SDK

Повторите запуск Buildozer и внимательно прочитайте сообщение об отсутствующем Android-инструменте. При проблемах с SDK документация Buildozer рекомендует проверить каталог ~/.buildozer и заново получить необходимые компоненты.

Смотреть полный лог

buildozer -v android debug

Ключ -v полезен при диагностике проблем сборки.

22. Мини-проект: счётчик

# main.py
from kivy.app import App
from kivy.uix.boxlayout import BoxLayout
from kivy.properties import NumericProperty

class MainLayout(BoxLayout):

    counter = NumericProperty(0)

    def increment(self):
        self.counter += 1

    def decrement(self):
        self.counter -= 1

class MyApp(App):
    pass

MyApp().run()
# my.kv
<MainLayout>:
    orientation: "vertical"
    spacing: 10
    padding: 20

    Label:
        text: str(root.counter)
        font_size: "48sp"

    BoxLayout:
        Button:
            text: "-1"
            on_release: root.decrement()

        Button:
            text: "+1"
            on_release: root.increment()
