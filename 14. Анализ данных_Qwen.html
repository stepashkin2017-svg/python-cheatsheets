1 Pandas, Series и DataFrame

Pandas — библиотека Python для работы с табличными данными. Основные объекты:

Series

Одномерный массив: один столбец данных с индексом.

DataFrame

Двумерная таблица: строки, столбцы, типы данных, индекс.

Пример создания DataFrame

import pandas as pd

df = pd.DataFrame({
    "city": ["Moscow", "SPb", "Moscow", "Kazan", "SPb"],
    "month": ["Jan", "Feb", "Jan", "Jan", "Feb"],
    "sales": [120, 90, 150, 80, 110],
    "status": ["active", "closed", "active", "active", "closed"],
    "age": [25, 30, None, 22, 35]
})

print(df)
Этот пример будет использоваться дальше во всех разделах.

4 value_counts — подсчёт значений

Метод value_counts() показывает, сколько раз каждое значение встречается в столбце.

Простой подсчёт

df["city"].value_counts()

Доли в процентах

df["status"].value_counts(normalize=True).mul(100).round(1)

Топ-2 значения

df["city"].value_counts().head(2)
Подходит для быстрых вопросов: «какой город встречается чаще?», «сколько активных и закрытых записей?».

5 groupby — группировка данных

groupby группирует строки по одному или нескольким столбцам и позволяет применить агрегацию: сумму, среднее, количество и другие функции.

Сумма продаж по городам

df.groupby("city")["sales"].sum()

Средние продажи по городам

df.groupby("city")["sales"].mean().round(1)

Группировка по нескольким столбцам

df.groupby(["city", "month"])["sales"].sum()

Несколько агрегаций сразу

df.groupby("city").agg(
    total_sales=("sales", "sum"),
    avg_sales=("sales", "mean"),
    records=("sales", "count")
).reset_index()
Логика простая: по чему группируем → что считаем → получаем результат.

6 pivot_table — сводная таблица

pivot_table строит таблицу вида «строки × столбцы» и агрегирует значения, как сводная таблица в Excel.

Продажи по городам и месяцам

pd.pivot_table(
    df,
    values="sales",
    index="city",
    columns="month",
    aggfunc="sum",
    fill_value=0
)

Средние продажи по статусу

pd.pivot_table(
    df,
    values="sales",
    index="city",
    columns="status",
    aggfunc="mean"
)

Несколько функций агрегации

pd.pivot_table(
    df,
    values="sales",
    index="city",
    columns="month",
    aggfunc=["sum", "mean"],
    fill_value=0
)

7 Фильтрация данных

Фильтрация оставляет только те строки, которые удовлетворяют условию.

Простой фильтр

df[df["sales"] > 100]

Несколько условий

df[(df["city"] == "Moscow") & (df["sales"] >= 120)]

Фильтр + выбор столбцов через loc

df.loc[df["status"] == "active", ["city", "sales"]]

Более читаемый синтаксис через query

df.query("sales > 100 and city == 'Moscow'")

Фильтр по списку значений

df[df["city"].isin(["Moscow", "SPb"])]
В булевых масках используйте &, | и ~, а не слова and, or, not.

8 Очистка данных: isnull, fillna, apply

Реальные данные часто содержат пропуски, лишний пробелы, разный регистр и несогласованные значения.

Сколько пропусков в каждом столбце

df.isnull().sum()

Найти строки с пропуском в столбце age

df[df["age"].isnull()]

Заполнить пропуски медианой

df["age"] = df["age"].fillna(df["age"].median())

Заполнить несколько столбцов разными значениями

df = df.fillna({
    "age": 0,
    "status": "unknown"
})

Удалить строки с пропусками в важных столбцах

df_clean = df.dropna(subset=["sales", "city"])

apply: очистить текст в столбце

df["city"] = df["city"].apply(lambda x: x.strip().title())

apply: создать категорию на основе значения

df["sales_label"] = df["sales"].apply(
    lambda x: "high" if x >= 120 else "normal"
)
Не злоупотребляйте параметром inplace=True. Современный стиль — явно присваивать результат обратно: df = df.fillna(...).

9 Генерация новых столбцов

Новые столбцы создают из существующих: бонусы, проценты, флаги, категории, отношения, признаки для моделей.

Простая арифметика

df["bonus"] = df["sales"] * 0.1

Округление нового столбца

df["bonus"] = df["bonus"].round(2)

assign: добавить несколько столбцов цепочкой

df = df.assign(
    profit=lambda d: d["sales"] - 20,
    sales_per_age=lambda d: d["sales"] / d["age"]
)

Булев признак

df["is_big_sale"] = df["sales"].gt(100)

Новый столбец через np.where

import numpy as np

df["priority"] = np.where(df["sales"] >= 120, "high", "low")

Интервальный признак через pd.cut

df["sales_bin"] = pd.cut(
    df["sales"],
    bins=[0, 100, 150],
    labels=["low", "high"]
)

10 Фиктивные переменные (dummy variables)

Фиктивные переменные превращают категориальные признаки в числовые столбцы со значениями 0/1 или True/False. Это часто нужно для машинного обучения.

Кодирование одного столбца

status_dummies = pd.get_dummies(df["status"], prefix="status")
print(status_dummies)

Присоединить фиктивные столбцы к исходной таблице

df_encoded = pd.concat(
    [df, pd.get_dummies(df["city"], prefix="city")],
    axis=1
)

Кодирование нескольких столбцов сразу

df_model = pd.get_dummies(
    df,
    columns=["city", "status"],
    drop_first=True
)

Если нужны именно числа 0 и 1

df_model = pd.get_dummies(
    df,
    columns=["city", "status"],
    drop_first=True
).astype(int)
Параметр drop_first=True убирает одну категорию, чтобы уменьшить риск мультиколлинеарности в линейных моделях.

12 Типичный рабочий цикл анализа

1. Загрузить → 2. Посмотреть → 3. Очистить → 4. Отфильтровать → 5. Сгруппировать → 6. Сделать вывод 
import pandas as pd

# 1. Загрузка данных
df = pd.read_csv("sales.csv")

# 2. Первичный осмотр
print(df.head())
print(df.info())

# 3. Очистка
df["city"] = df["city"].str.strip().str.title()
df["age"] = df["age"].fillna(df["age"].median())

# 4. Фильтрация
active_df = df[df["status"] == "active"]

# 5. Группировка и агрегация
summary = (
    active_df
    .groupby("city")
    .agg(
        total_sales=("sales", "sum"),
        avg_sales=("sales", "mean"),
        count=("sales", "count")
    )
    .sort_values("total_sales", ascending=False)
)

# 6. Результат
print(summary)

13 Главное правило Pandas

ЗАГРУЗИЛ ↓ ПОСМОТРЕЛ ДАННЫЕ ↓ ОЧИСТИЛ ↓ ОТФИЛЬТРОВАЛ ↓ СГРУППИРОВАЛ ↓ СДЕЛАЛ ВЫВОД
Не начинайте сразу со сложных моделей. Сначала убедитесь, что данные загружены корректно, типы столбцов правильные, пропуски обработаны, а фильтры и группировки дают понятный результат.
