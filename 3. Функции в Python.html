Функции в Python

От простого def до декораторов и генераторов. Сначала посмотрите, в каком порядке пишутся параметры.

Сигнатура
def name(a, /, b, d=0, *args, c, **kwargs) -> int:
1. a, / — только по позиции 2. b — позиция или имя 3. d=0 — по умолчанию 4. *args — лишние позиционные 5. c — только по имени 6. **kwargs — лишние именованные
Основы Аргументы Области видимости Продвинутое

Основы

Определение и вызов

Без return функция вернёт None.

def greet(name):
    """Возвращает приветствие."""
    return "Привет, " + name + "!"

msg = greet("Аня")   # вызов
print(msg)

Значения по умолчанию

Параметры со значением по умолчанию идут после обычных.

def power(base, exp=2):
    return base ** exp

power(3)               # 9
power(3, 3)            # 27
power(exp=3, base=2)   # 8

Несколько возвращаемых значений

На самом деле возвращается один кортеж.

def min_max(items):
    return min(items), max(items)

lo, hi = min_max([4, 1, 9])   # 1, 9

Аннотации типов

Python их не проверяет. Они помогают читателю, IDE и mypy.

def area(w: float, h: float = 1.0) -> float:
    return w * h

def find(xs: list[int], x: int) -> int | None:
    return xs.index(x) if x in xs else None

Аргументы

*args и **kwargs

*args собирает позиционные аргументы в кортеж, **kwargs — именованные в словарь.

def log(*args, **kwargs):
    print(args)
    print(kwargs)

log(1, 2, sep="-")
# (1, 2)
# {'sep': '-'}

nums = [1, 2, 3]
opts = {"sep": "-"}
log(*nums, **opts)   # распаковка

Только позиционные и только ключевые

До / — только по позиции, после * — только по имени.

def f(a, b, /, c, *, d):
    ...

f(1, 2, 3, d=4)          # ok
f(1, 2, c=3, d=4)        # ok
f(a=1, b=2, c=3, d=4)    # TypeError

Ловушка: изменяемое значение по умолчанию

Значение по умолчанию создаётся один раз, при определении функции. Список будет общим для всех вызовов.

# плохо
def add(x, bucket=[]):
    bucket.append(x)
    return bucket

# хорошо
def add(x, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(x)
    return bucket

lambda

Одно выражение, без return. Для сложной логики берите обычный def.

square = lambda x: x ** 2

words = ["кот", "слон", "ёж"]
sorted(words, key=lambda w: len(w))

Области видимости

global и nonlocal

Поиск имени идёт так: Local → Enclosing → Global → Built-in.

count = 0

def inc():
    global count
    count += 1

def outer():
    n = 0
    def inner():
        nonlocal n
        n += 1
    inner()
    return n   # 1

Замыкание: функция, которая делает функции

Внутренняя функция помнит переменные внешней.

def multiplier(k):
    def mul(x):
        return x * k
    return mul

double = multiplier(2)
double(5)   # 10

Продвинутое

Декоратор

@functools.wraps сохраняет имя и docstring исходной функции.

import functools

def logged(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("вызов", func.__name__)
        return func(*args, **kwargs)
    return wrapper

@logged
def hello():
    print("hi")

Генератор

yield отдаёт значения по одному и приостанавливает функцию между ними.

def countdown(n):
    while n > 0:
        yield n
        n -= 1

for i in countdown(3):
    print(i)   # 3, 2, 1

async def

Вызов создаёт корутину. Она выполняется через await или asyncio.run.

import asyncio

async def fetch(n):
    await asyncio.sleep(1)
    return n * 2

async def main():
    res = await asyncio.gather(fetch(1), fetch(2))
    print(res)   # [2, 4]

asyncio.run(main())

Методы класса

Первый параметр — self (экземпляр) или cls (класс). Это соглашение об именах.

class Counter:
    def __init__(self, start=0):
        self.n = start

    def inc(self):          # метод экземпляра
        self.n += 1

    @classmethod
    def zero(cls):          # получает класс
        return cls(0)

    @staticmethod
    def is_valid(x):        # ни self, ни cls
        return x >= 0
