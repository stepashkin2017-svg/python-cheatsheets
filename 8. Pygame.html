Виртуальное окружение и зависимости

Окружение изолирует библиотеки проекта от системного Python. Команды выполняются в терминале в папке проекта.

1. Создание окружения

Создаёт папку .venv с отдельной копией интерпретатора.

mkdir mygame
cd mygame
python -m venv .venv          # Windows: py -m venv .venv
# на Linux/macOS при необходимости: python3 -m venv .venv

2. Активация

После активации в начале строки терминала появится (.venv).

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# Windows (cmd)
.venv\Scripts\activate.bat
# Linux / macOS
source .venv/bin/activate

Если PowerShell блокирует скрипт: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.

3. Установка pygame

python -m pip install --upgrade pip
pip install pygame
pip show pygame        # версия и путь
pip list               # все пакеты окружения

4. Проверка установки

python -c "import pygame; print(pygame.version.ver)"
# встроенная демо-игра:
python -m pygame.examples.aliens

5. Выгрузка зависимостей

pip freeze выводит установленные пакеты с точными версиями. Сохраняем в файл.

pip freeze > requirements.txt
cat requirements.txt     # Windows: type requirements.txt
# pygame==2.6.1

Версия в вашем файле может отличаться — это нормально.

6. Установка из requirements.txt

Так проект разворачивают на другом компьютере или у коллеги.

python -m venv .venv
source .venv/bin/activate       # или Activate на Windows
pip install -r requirements.txt

7. Выход и удаление

deactivate            # выйти из окружения
rm -rf .venv          # удалить (Windows: rmdir /s /q .venv)

8. .gitignore

Окружение в репозиторий не кладут — только requirements.txt.

# .gitignore
.venv/
__pycache__/
*.pyc

Структура проекта

mygame/

├── assets/
│   ├── images/
│   └── sounds/

├── requirements.txt

pygame или pygame-ce

pygame-ce — активно развиваемая community-версия. Модуль называется так же (import pygame), но ставить обе в одно окружение нельзя.

pip uninstall pygame
pip install pygame-ce

Заготовка игры

Любая игра на pygame — это бесконечный цикл из трёх шагов: события → обновление → отрисовка.

Минимальный шаблон

import sys
import pygame

pygame.init()

WIDTH, HEIGHT = 800, 600
FPS = 60
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Моя игра")
clock = pygame.time.Clock()

running = True
while running:
    dt = clock.tick(FPS) / 1000        # секунды с прошлого кадра

    # 1. События
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            running = False

    # 2. Обновление логики
    # ...

    # 3. Отрисовка
    screen.fill((20, 24, 40))          # очистить кадр
    # ... рисуем ...
    pygame.display.flip()              # показать кадр

pygame.quit()
sys.exit()

Структура с классом Game

Когда игра растёт, удобно разделить код на методы.

class Game:
    def __init__(self):
        pygame.init()
        self.screen = pygame.display.set_mode((800, 600))
        self.clock = pygame.time.Clock()
        self.running = True

    def events(self):
        for e in pygame.event.get():
            if e.type == pygame.QUIT:
                self.running = False

    def update(self, dt): ...

    def draw(self):
        self.screen.fill((0, 0, 0))
        pygame.display.flip()

    def run(self):
        while self.running:
            dt = self.clock.tick(60) / 1000
            self.events(); self.update(dt); self.draw()
        pygame.quit()

if __name__ == "__main__":
    Game().run()

Рисование примитивов

Координаты в пикселях: (0, 0) — левый верхний угол, X вправо, Y вниз. Цвет — кортеж (R, G, B) от 0 до 255.

Цвета

WHITE = (255, 255, 255)

Прямоугольник

Последний аргумент — толщина контура (0 — заливка), border_radius скругляет углы.

pygame.draw.rect(screen, WHITE, (50, 50, 200, 100), 3)
pygame.draw.rect(screen, RED, r, border_radius=12)

Круг, эллипс, дуга

Линии и многоугольник

Поверхности (Surface)

Отдельный «холст», который потом рисуется на экран. Прозрачность — флагом SRCALPHA.

surf = pygame.Surface((100, 100), pygame.SRCALPHA)
pygame.draw.circle(surf, (255, 0, 0, 120), (50, 50), 50)
screen.blit(surf, (200, 200))

Rect — главный помощник

Хранит положение и размер, даёт готовые точки привязки.

r = pygame.Rect(100, 100, 80, 40)   # x, y, ширина, высота
r.center, r.topleft, r.midbottom    # точки привязки
r.right, r.bottom                   # края
r.center = (400, 300)               # поставить по центру
r.move_ip(5, 0)                     # сдвинуть на месте
r.clamp_ip(screen.get_rect())       # не выходить за экран

События и ввод

Очередь событий

События приходят в pygame.event.get(). Тип — в event.type.

for event in pygame.event.get():
    if event.type == pygame.QUIT: ...
    elif event.type == pygame.KEYDOWN:
        event.key       # pygame.K_SPACE и т.д.
    elif event.type == pygame.MOUSEBUTTONDOWN:
        event.pos, event.button   # 1 лев, 2 средняя, 3 прав

Одиночное нажатие

Срабатывает один раз при нажатии клавиши. Подходит для прыжка, выстрела, паузы.

if event.type == pygame.KEYDOWN:
    if event.key == pygame.K_SPACE:
        shoot()
    if event.key == pygame.K_p:
        paused = not paused

Удержание клавиши

get_pressed() опрашивает состояние клавиш прямо сейчас. Для плавного движения.

keys = pygame.key.get_pressed()
if keys[pygame.K_LEFT]  or keys[pygame.K_a]: x -= speed * dt
if keys[pygame.K_RIGHT] or keys[pygame.K_d]: x += speed * dt

Мышь

mx, my = pygame.mouse.get_pos()
left, middle, right = pygame.mouse.get_pressed()
if event.type == pygame.MOUSEMOTION:
    event.pos, event.rel          # позиция и сдвиг
if event.type == pygame.MOUSEWHEEL:

Движение и время

Clock и FPS

clock = pygame.time.Clock()
dt = clock.tick(60) / 1000     # ограничить 60 кадров/с, dt в секундах
clock.get_fps()                # текущий FPS
pygame.time.get_ticks()        # мс с запуска игры

Скорость не зависит от FPS

Умножайте скорость (пикселей в секунду) на dt. Тогда игра идёт одинаково на слабых и мощных компьютерах.

speed = 300                    # px/с
x += speed * dt
rect.x = round(x)              # Rect хранит целые

Вектор скорости

Vector2 удобен для диагоналей, направлений и расстояний.

from pygame.math import Vector2
pos = Vector2(100, 100)
vel = Vector2(1, 1)
if vel.length() > 0:
    vel = vel.normalize()      # одинаковая скорость по диагонали
pos += vel * speed * dt
pos.distance_to(Vector2(0, 0))

Отскок от стен

ball.x += vx * dt
if ball.left < 0 or ball.right > WIDTH:
    vx = -vx
if ball.top < 0 or ball.bottom > HEIGHT:
    vy = -vy

Гравитация и прыжок

vy += 1500 * dt                # ускорение вниз

Столкновения и спрайты

Столкновения прямоугольников

Класс Sprite

Спрайт имеет image и rect; метод update вызывается группой.

class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((40, 40))
        self.image.fill((80, 200, 120))
        self.rect = self.image.get_rect(center=(400, 500))
        self.speed = 300
    def update(self, dt):
        k = pygame.key.get_pressed()
        self.rect.x += (k[pygame.K_RIGHT] - k[pygame.K_LEFT]) * self.speed * dt
        self.rect.clamp_ip(pygame.display.get_surface().get_rect())

Группы спрайтов

all_sprites = pygame.sprite.Group()
enemies = pygame.sprite.Group()
player = Player()
all_sprites.add(player)

all_sprites.update(dt)       # обновить всех
all_sprites.draw(screen)     # нарисовать всех

Столкновения спрайтов

hits = pygame.sprite.spritecollide(player, enemies, True)

if hits:
    score += len(hits)

Точные столкновения по маске

Учитывают форму непрозрачных пикселей, а не весь прямоугольник.

self.mask = pygame.mask.from_surface(self.image)

def update(self, dt):

    if self.rect.top > 600:

Состояния игры

Один переменный флаг переключает меню, игру и «Game Over».

state = "menu"          # menu / play / over
if state == "menu":
    draw_menu()
elif state == "play":
    update(dt); draw_game()
else:

Мини-игра: «Уворачивайся»

Полный пример

Игрок двигается стрелками, уворачивается от падающих блоков. Очки — время выживания. После проигрыша R начинает заново.

import random, sys
import pygame

pygame.init()
W, H = 480, 640
screen = pygame.display.set_mode((W, H))
pygame.display.set_caption("Уворачивайся")
clock = pygame.time.Clock()
font = pygame.font.SysFont("arial", 28)

player = pygame.Rect(W // 2 - 25, H - 60, 50, 30)
px, enemies, score, spawn, alive = float(player.x), [], 0.0, 0.0, True

def reset():
    global px, enemies, score, spawn, alive
    px, enemies, score, spawn, alive = W // 2 - 25.0, [], 0.0, 0.0, True

while True:
    dt = clock.tick(60) / 1000
    for e in pygame.event.get():
        if e.type == pygame.QUIT:
            pygame.quit(); sys.exit()
        if e.type == pygame.KEYDOWN and e.key == pygame.K_r and not alive:
            reset()

    if alive:
        k = pygame.key.get_pressed()
        px += (k[pygame.K_RIGHT] - k[pygame.K_LEFT]) * 400 * dt
        px = max(0, min(W - player.w, px))
        player.x = round(px)

        spawn += dt
        if spawn > 0.5:
            spawn = 0
            enemies.append(pygame.Rect(random.randint(0, W - 30), -30, 30, 30))
        for en in enemies:
            en.y += round(300 * dt)
        enemies = [en for en in enemies if en.top < H]

        if player.collidelist(enemies) != -1:
            alive = False
        score += dt

    screen.fill((20, 24, 40))
    pygame.draw.rect(screen, (80, 200, 120), player, border_radius=6)
    for en in enemies:
        pygame.draw.rect(screen, (230, 80, 80), en, border_radius=4)
    screen.blit(font.render(f"Очки: {int(score)}", True, (255, 255, 255)), (10, 10))
    if not alive:
        msg = font.render("Игра окончена. R — заново", True, (255, 220, 120))
        screen.blit(msg, msg.get_rect(center=(W // 2, H // 2)))
    pygame.display.flip()
Совет: каждый кадр — это «события → обновление → отрисовка». Держите эти три части отдельно, и код останется понятным по мере роста игры.
