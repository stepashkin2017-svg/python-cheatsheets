1. Быстрый старт Pillow

Pillow — современная библиотека Python для открытия, обработки и сохранения изображений. Импорт выполняется через пакет PIL.

Установка

pip install Pillow

Импорт

from PIL import Image

img = Image.open("photo.jpg")

Название библиотеки — Pillow, но основной импорт: from PIL ....

Минимальное приложение

from PIL import Image

img = Image.open("photo.jpg")
img = img.resize((800, 600))
img.save("result.jpg")

print("Готово!")

2. Открытие изображения Image.open()

Pillow определяет формат файла автоматически по его содержимому и предоставляет объект Image.

Открыть файл

from PIL import Image

img = Image.open("photo.jpg")
print(img)

Информация об изображении

print(img.size)    # (ширина, высота)
print(img.width)
print(img.height)
print(img.mode)    # например RGB
print(img.format)  # JPEG

Показать изображение

img.show()

Откроет изображение в стандартном просмотрщике ОС.

Безопасная проверка файла

try:
    img = Image.open("photo.jpg")
    img.load()
except FileNotFoundError:
    print("Файл не найден")
except Exception as e:
    print("Ошибка:", e)

3. Размер, обрезка и геометрия

Операции resize(), crop(), rotate(), transpose() возвращают обработанное изображение.

Изменение размера

small = img.resize((400, 300))
small.save("small.jpg")

Сохранить пропорции

from PIL import Image

img.thumbnail((800, 800))
# изменяет img на месте
img.save("thumb.jpg")

thumbnail() уменьшает изображение с сохранением пропорций.

Обрезка crop()

# (left, top, right, bottom)
part = img.crop((100, 50, 500, 350))
part.save("crop.jpg")

Поворот

rotated = img.rotate(90)
rotated.save("rotated.jpg")

Отражение

from PIL import Image

mirror = img.transpose(
    Image.Transpose.FLIP_LEFT_RIGHT
)

Другие преобразования

img.transpose(Image.Transpose.FLIP_TOP_BOTTOM)

img.rotate(45, expand=True)

expand=True увеличивает холст, чтобы повёрнутое изображение полностью поместилось.

4. Цветовые режимы и преобразования

Режим изображения определяет способ хранения пикселей: RGB, RGBA, L, 1 и другие.

RGB → оттенки серого

gray = img.convert("L")
gray.save("gray.jpg")

RGB → RGBA

rgba = img.convert("RGBA")
print(rgba.mode)  # RGBA

Канал A — альфа-канал прозрачности.

Чёрно-белое

bw = img.convert("L").point(
    lambda p: 255 if p > 128 else 0
)
bw.save("bw.png")

Проверка режима

print(img.mode)

if img.mode != "RGB":
    img = img.convert("RGB")

5. Пиксели

Пиксель можно получить через getpixel() и изменить через putpixel(). Для RGB обычно используются кортежи (R, G, B).

Получить пиксель

img = Image.open("photo.jpg").convert("RGB")

pixel = img.getpixel((10, 20))
print(pixel)
# например: (120, 80, 200)

Изменить пиксель

img.putpixel((10, 20), (255, 0, 0))

Точка (10, 20) станет красной.

Изменить область

for y in range(100):
    for x in range(100):
        img.putpixel(
            (x, y), (255, 0, 0)
        )

Пример закрашивает квадрат 100×100 пикселей.

6. Рисование: ImageDraw

Модуль PIL.ImageDraw позволяет рисовать линии, прямоугольники, эллипсы, многоугольники и текст.

Подготовка

from PIL import Image, ImageDraw

img = Image.new("RGB", (600, 400), "white")
draw = ImageDraw.Draw(img)

Линия

draw.line(
    (20, 20, 500, 100),
    fill="red",
    width=5
)

Прямоугольник

draw.rectangle(
    (50, 50, 250, 180),
    fill="skyblue",
    outline="blue",
    width=3
)

Эллипс

draw.ellipse(
    (300, 50, 500, 200),
    fill="yellow",
    outline="black",
    width=3
)

Многоугольник

draw.polygon(
    [(100, 300), (200, 220), (300, 300)],
    fill="green"
)

Текст

draw.text(
    (30, 330),
    "Привет, Pillow!",
    fill="black"
)

7. Текст и шрифты

Для шрифтов TrueType/OpenType удобно использовать ImageFont.truetype().

Подключить шрифт

from PIL import ImageFont

font = ImageFont.truetype(
    "arial.ttf",
    32
)

draw.text(
    (20, 20),
    "Привет!",
    font=font,
    fill="black"
)

Размер текста

bbox = draw.textbbox(
    (0, 0),
    "Привет!",
    font=font
)

width = bbox[2] - bbox[0]
height = bbox[3] - bbox[1]

print(width, height)

Выравнивание

draw.text(
    (300, 200),
    "Центр",
    font=font,
    anchor="mm",
    fill="black"
)

anchor="mm" задаёт центральную точку текста.

8. Фильтры и улучшение изображения

Модуль PIL.ImageFilter содержит готовые фильтры: размытие, резкость, контуры и другие.

Размытие

from PIL import ImageFilter

blur = img.filter(
    ImageFilter.BLUR
)

Gaussian Blur

blur = img.filter(
    ImageFilter.GaussianBlur(5)
)

Резкость

sharp = img.filter(
    ImageFilter.SHARPEN
)

Контуры

edges = img.filter(
    ImageFilter.FIND_EDGES
)

DETAIL

detail = img.filter(
    ImageFilter.DETAIL
)

Контраст и яркость

from PIL import ImageEnhance

bright = ImageEnhance.Brightness(
    img
).enhance(1.5)

contrast = ImageEnhance.Contrast(
    img
).enhance(1.5)

9. Прозрачность и альфа-канал

Формат RGBA содержит четыре канала: красный, зелёный, синий и альфа-канал.

Создать прозрачное изображение

img = Image.new(
    "RGBA",
    (500, 300),
    (255, 255, 255, 0)
)

Последнее значение 0 — полностью прозрачно, 255 — непрозрачно.

Полупрозрачная фигура

draw = ImageDraw.Draw(img)

draw.rectangle(
    (50, 50, 300, 200),
    fill=(255, 0, 0, 128)
)

Наложение изображений

background = Image.open("bg.png").convert("RGBA")
foreground = Image.open("logo.png").convert("RGBA")

background.alpha_composite(
    foreground,
    (50, 50)
)

10. Сохранение и конвертация

Метод save() записывает изображение в файл. Формат можно задать расширением или параметром format.

JPEG

img.save(
    "result.jpg",
    quality=90
)

PNG

img.save(
    "result.png"
)

PNG особенно удобен для изображений с прозрачностью.

WEBP

img.save(
    "result.webp",
    quality=85
)

Конвертация JPEG → PNG

img = Image.open("photo.jpg")
img.save("photo.png")

Для JPEG с прозрачностью сначала нужен подходящий режим, например RGBA для PNG.

Сохранить копию

copy = img.copy()
copy.save("copy.png")

11. Папки и пакетная обработка

Pillow удобно использовать вместе с pathlib для обработки большого количества изображений.

Все JPG в папке

from pathlib import Path

folder = Path("photos")

for path in folder.glob("*.jpg"):
    img = Image.open(path)
    print(path.name, img.size)

Создать миниатюры

from pathlib import Path
from PIL import Image

for path in Path("photos").glob("*.jpg"):
    img = Image.open(path)
    img.thumbnail((300, 300))

    out = Path("thumbs") / path.name
    img.save(out)

12. Мини-проект: генератор картинки с надписью

Пример объединяет создание изображения, рисование, шрифт и сохранение результата.

Готовый пример

from PIL import Image, ImageDraw, ImageFont

# 1. Создаём холст
img = Image.new(
    "RGB",
    (800, 450),
    "#EEF3F8"
)

# 2. Создаём объект рисования
draw = ImageDraw.Draw(img)

# 3. Подключаем шрифт
font = ImageFont.truetype(
    "arial.ttf",
    48
)

# 4. Рисуем заголовок
draw.text(
    (400, 150),
    "Pillow",
    font=font,
    anchor="mm",
    fill="#13203A"
)

# 5. Рисуем прямоугольник
draw.rounded_rectangle(
    (220, 220, 580, 320),
    radius=20,
    fill="#0C7C86"
)

# 6. Второй текст
small_font = ImageFont.truetype(
    "arial.ttf",
    28
)

draw.text(
    (400, 270),
    "Изображения в Python",
    font=small_font,
    anchor="mm",
    fill="white"
)

# 7. Сохраняем
img.save("pillow_result.png")

print("Готово!")

14. Что запомнить

Логика работы с Pillow

Image.open()
      ↓
получили объект Image
      ↓
resize / crop / rotate / convert
      ↓
draw / text / filter / enhance
      ↓
show() или save()

Главная идея

Почти все операции выполняются над объектом Image. Многие методы возвращают новый объект, поэтому удобно строить цепочку обработки:

result = (
    Image.open("photo.jpg")
    .convert("L")
    .resize((800, 600))
)

Важное различие

resize(), crop(), rotate() обычно возвращают новое изображение, а thumbnail() изменяет текущий объект на месте.
