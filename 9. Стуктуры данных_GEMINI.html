Обзор и сравнение

Структура данных хранит набор значений и определяет, как с ним работать. Главные отличия: изменяемость, порядок и уникальность.

Общие операции

Работают для большинства структур.

len(x)          # количество элементов
3 in x          # есть ли элемент
for item in x:  # перебор
    ...
min(x), max(x), sum(x)   # для чисел
sorted(x)       # новый отсортированный список

Преобразования между типами

list((1, 2))            # [1, 2]
tuple([1, 2])           # (1, 2)
set([1, 1, 2])          # {1, 2}
frozenset([1, 2])       # frozenset({1, 2})
dict([("a", 1)])        # {'a': 1}
dict(zip("ab", [1, 2])) # {'a': 1, 'b': 2}
list({"a": 1})          # ['a'] — ключи

Скорость проверки in

Для больших данных выбор структуры влияет на скорость.

x in список       # перебор: O(n)
x in кортеж       # перебор: O(n)
x in множество    # хеш: в среднем O(1)
k in словарь      # хеш: в среднем O(1)

Списки list

Упорядоченная изменяемая коллекция любых значений. Элементы нумеруются с 0.

Создание

a = [1, 2, 3]
b = []                  # пустой
c = list("abc")         # ['a', 'b', 'c']
d = [0] * 3             # [0, 0, 0]
e = list(range(5))      # [0, 1, 2, 3, 4]
mix = [1, "a", 2.5, [1, 2]]

Индексы и срезы

a = [10, 20, 30, 40, 50]
a[0]       # 10
a[-1]      # 50
a[1:3]     # [20, 30]
a[:2]      # [10, 20]
a[::2]     # [10, 30, 50]
a[::-1]    # [50, 40, 30, 20, 10]

Изменение элементов

a[0] = 99         # [99, 20, 30, 40, 50]
a[1:3] = [0, 0]   # замена среза
a += [60]         # добавить в конец

Добавление

a = [1, 2]
a.append(3)         # [1, 2, 3]
a.insert(0, 9)      # [9, 1, 2, 3]
a.extend([4, 5])    # [9, 1, 2, 3, 4, 5]
a + [6]             # новый список

Удаление

a = [1, 2, 3, 2]
a.remove(2)    # [1, 3, 2] — первое значение 2
a.pop()        # вернёт 2, список [1, 3]
a.pop(0)       # вернёт 1, список [3]
del a[0]       # удалить по индексу
a.clear()      # []

Поиск и подсчёт

a = [5, 3, 5, 1]
a.index(3)     # 1 — позиция
a.count(5)     # 2 — сколько раз
3 in a         # True
len(a)         # 4

Сортировка и разворот

sort() меняет список, sorted() возвращает новый.

n = [3, 1, 2]
n.sort()                    # [1, 2, 3]
n.sort(reverse=True)        # [3, 2, 1]
sorted(n)                   # новый список
words = ["ccc", "a", "bb"]
words.sort(key=len)         # ['a', 'bb', 'ccc']
n.reverse()                 # развернуть на месте

Распаковка

x, y, z = [1, 2, 3]
first, *rest = [1, 2, 3, 4]    # 1, [2, 3, 4]
*init, last = [1, 2, 3]        # [1, 2], 3

Генератор списка

[x * x for x in range(5)]            # [0, 1, 4, 9, 16]
[x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]
[c.upper() for c in "abc"]           # ['A', 'B', 'C']

Копирование

b = a даёт вторую ссылку на тот же список. Для копии используйте copy(); для вложенных структур — deepcopy.

a = [1, 2]
b = a            # один объект
c = a.copy()     # копия (то же: a[:] , list(a))
import copy
d = copy.deepcopy([[1], [2]])   # полная копия

Вложенные списки

Ловушка: умножение копирует ссылки, а не списки.

m = [[1, 2], [3, 4]]
m[1][0]                        # 3
bad  = [[0] * 3] * 3           # три ссылки на один список
good = [[0] * 3 for _ in range(3)]
bad[0][0] = 1                  # [[1,0,0],[1,0,0],[1,0,0]]

Перебор

for x in [10, 20]:
    print(x)
for i, x in enumerate(["a", "b"]):
    print(i, x)               # 0 a / 1 b

Кортежи tuple

Упорядоченная неизменяемая последовательность. Подходит для данных, которые не должны меняться: координаты, записи, возвращаемые значения.

Создание

t = (1, 2, 3)
t = 1, 2, 3            # скобки необязательны
one = (5,)             # кортеж из одного элемента: нужна запятая
empty = ()
tuple([1, 2])          # (1, 2)
type((5))              # <class 'int'> — просто скобки

Доступ и срезы

t = (10, 20, 30, 40)
t[0]       # 10
t[-1]      # 40
t[1:3]     # (20, 30)
len(t)     # 4
20 in t    # True

Неизменяемость

t = (1, 2, 3)
t[0] = 9           # TypeError
t = t + (4,)       # (1, 2, 3, 4) — создан новый кортеж
# но изменяемый элемент внутри менять можно:
m = ([1], 2)
m[0].append(5)     # ([1, 5], 2)

Методы

Только два, раз кортеж менять нельзя.

t = (1, 2, 2, 3)
t.count(2)     # 2
t.index(3)     # 3

Распаковка и обмен

x, y = (10, 20)
a, b = b, a            # обмен значений
first, *rest = (1, 2, 3)

Несколько значений из функции

def min_max(nums):
    return min(nums), max(nums)    # возвращается кортеж

lo, hi = min_max([4, 1, 9])        # 1, 9

Кортеж как ключ словаря

Изменяемый список ключом быть не может, а кортеж — может.

grid = {(0, 0): "старт", (2, 3): "финиш"}
grid[(2, 3)]      # 'финиш'

Именованный кортеж

Элементы доступны по именам, как у объекта.

from collections import namedtuple
Point = namedtuple("Point", "x y")
p = Point(3, 4)
p.x, p[1]         # (3, 4)
p._replace(x=10)  # Point(x=10, y=4)

Словари dict

Набор пар «ключ: значение». Доступ по ключу, ключи уникальны и должны быть неизменяемыми (строки, числа, кортежи). Порядок вставки сохраняется (Python 3.7+).

Создание

d = {"name": "Аня", "age": 20}
e = {}                         # пустой
f = dict(a=1, b=2)             # {'a': 1, 'b': 2}
g = dict([("x", 1), ("y", 2)])
h = dict.fromkeys(["a", "b"], 0)   # {'a': 0, 'b': 0}

Чтение значения

d[k] вызывает KeyError, если ключа нет. get безопаснее.

d["name"]              # 'Аня'
d["city"]              # KeyError
d.get("city")          # None
d.get("city", "—")     # '—' — значение по умолчанию

Добавление и изменение

d["city"] = "Москва"          # добавить
d["age"] = 21                 # изменить
d.update({"age": 22, "x": 1}) # несколько сразу
d.setdefault("tags", [])      # создать, если нет
d | {"z": 0}                  # новый словарь (Python 3.9+)

Удаление

d.pop("x")         # вернёт значение и удалит
d.pop("q", None)   # без ошибки, если нет
del d["city"]
d.popitem()        # удалить последнюю пару
d.clear()          # {}

keys, values, items

d = {"a": 1, "b": 2}
d.keys()      # dict_keys(['a', 'b'])
d.values()    # dict_values([1, 2])
d.items()     # dict_items([('a', 1), ('b', 2)])
"a" in d      # True — проверка по ключам
list(d)       # ['a', 'b']

Перебор

for k in d:               print(k)
for v in d.values():      print(v)
for k, v in d.items():    print(k, v)   # a 1 / b 2

Генератор словаря

{x: x * x for x in range(4)}      # {0: 0, 1: 1, 2: 4, 3: 9}
{k: v for k, v in d.items() if v > 1}   # {'b': 2}
{v: k for k, v in d.items()}      # поменять ключи и значения

Подсчёт: частота слов

count = {}
for w in "a b a c a b".split():
    count[w] = count.get(w, 0) + 1
# {'a': 3, 'b': 2, 'c': 1}
# проще: collections.Counter("a b a c a b".split())

Сортировка

scores = {"Аня": 5, "Боря": 3, "Вика": 4}
sorted(scores)                          # по ключам
sorted(scores.items(), key=lambda kv: kv[1])
# [('Боря', 3), ('Вика', 4), ('Аня', 5)]
max(scores, key=scores.get)             # 'Аня'

Вложенные словари

user = {"name": "Аня",
        "addr": {"city": "Москва", "zip": "101000"},
        "langs": ["ru", "en"]}
user["addr"]["city"]       # 'Москва'
user["langs"][0]           # 'ru'
user.get("addr", {}).get("street", "—")   # безопасно

Объединение и копия

a = {"x": 1}; b = {"y": 2}
c = {**a, **b}        # {'x': 1, 'y': 2}
a | b                 # то же (3.9+)
d = a.copy()          # поверхностная копия

Множества set

Неупорядоченный набор уникальных неизменяемых элементов. Мгновенная проверка принадлежности и операции теории множеств.

Создание

Пустое множество — только set(): {} создаёт словарь.

s = {1, 2, 3}
e = set()                    # пустое
set("hello")                 # {'h', 'e', 'l', 'o'}
set([1, 1, 2, 2, 3])         # {1, 2, 3}
type({})                     # <class 'dict'>

Добавление и удаление

s = {1, 2}
s.add(3)            # {1, 2, 3}
s.update([4, 5])    # {1, 2, 3, 4, 5}
s.remove(5)         # KeyError, если нет
s.discard(10)       # без ошибки
s.pop()             # удалит произвольный элемент
s.clear()

Проверка и размер

s = {1, 2, 3}
2 in s         # True — очень быстро
len(s)         # 3
s[0]           # TypeError — индексов нет

Операции над множествами

a = {1, 2, 3}
b = {3, 4}
a | b     # {1, 2, 3, 4} — объединение
a & b     # {3}           — пересечение
a - b     # {1, 2}        — разность
a ^ b     # {1, 2, 4}     — симметрическая разность

Методы-аналоги

a.union(b)                 # a | b
a.intersection(b)          # a & b
a.difference(b)            # a - b
a.symmetric_difference(b)  # a ^ b
a |= {9}                   # изменить на месте

Сравнение множеств

{1, 2} <= {1, 2, 3}          # True — подмножество
{1, 2, 3} >= {1, 2}          # True — надмножество
{1, 2}.issubset({1, 2, 3})   # True
{1, 2}.isdisjoint({3, 4})    # True — общих нет

Удаление дубликатов

nums = [3, 1, 3, 2, 1]
list(set(nums))              # порядок не гарантируется
list(dict.fromkeys(nums))    # [3, 1, 2] — с сохранением порядка

Генератор множества

{x % 3 for x in range(10)}      # {0, 1, 2}
{w.lower() for w in ["A", "a", "B"]}   # {'a', 'b'}

Практика: общие и разные элементы

mon = {"Аня", "Боря", "Вика"}
tue = {"Боря", "Гоша"}
mon & tue      # {'Боря'} — были оба дня
mon | tue      # все, кто приходил
mon - tue      # только в понедельник

Неизменяемые множества frozenset

То же множество, но после создания не меняется. Поэтому оно хешируемо: может быть ключом словаря и элементом другого множества.

Создание

fs = frozenset([1, 2, 2, 3])   # frozenset({1, 2, 3})
frozenset("abc")
frozenset()                    # пустое

Нельзя менять

fs = frozenset({1, 2})
fs.add(3)       # AttributeError
fs.remove(1)    # AttributeError
# нет add, remove, discard, pop, clear, update

Можно читать и вычислять

Все операции из set, которые не меняют объект, работают и возвращают новый frozenset.

a = frozenset({1, 2, 3})
b = frozenset({3, 4})
2 in a           # True
a | b            # frozenset({1, 2, 3, 4})
a & b            # frozenset({3})
a <= a | b       # True

Ключ словаря

Обычное множество ключом быть не может, frozenset — может.

{ {1, 2}: "x" }                    # TypeError
pairs = {frozenset({1, 2}): "пара"}
pairs[frozenset({2, 1})]           # 'пара' — порядок не важен

Множество множеств

groups = {frozenset({1, 2}), frozenset({3})}
frozenset({1, 2}) in groups        # True
{ {1}, {2} }                       # TypeError

Практика: неупорядоченные пары

Пары (A, B) и (B, A) считаются одним ребром.

edges = {frozenset(("A", "B")), frozenset(("B", "A")),
         frozenset(("B", "C"))}
len(edges)    # 2 — первая и вторая совпали
