HTML: основы вёрстки

HTML описывает структуру и содержимое страницы с помощью тегов. Тег бывает парным (<p>…</p>) и одиночным (<img>); свойства задаются атрибутами.

Каркас страницы

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Моя страница</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Привет!</h1>
</body>
</html>

Текст и ссылки

<h1>Заголовок</h1>  <!-- h1…h6 -->
<p>Абзац с <strong>жирным</strong> и <em>курсивом</em>.<br>Новая строка.</p>
<hr>
<a href="https://example.com" target="_blank">Ссылка</a>
<a href="/about">Внутренняя</a>

Списки и изображения

<ul><li>Маркированный</li><li>список</li></ul>
<ol><li>Нумерованный</li></ol>
<img src="cat.png" alt="Кот" width="200">

Таблица

<table>
  <tr><th>Имя</th><th>Балл</th></tr>
  <tr><td>Аня</td><td>5</td></tr>
</table>

Формы

method — GET или POST, action — куда отправить, name — ключ данных на сервере.

<form action="/add" method="post">
  <label for="n">Имя</label>
  <input id="n" name="name" type="text" required>
  <input name="age" type="number" min="1">
  <input name="pwd" type="password">
  <textarea name="msg"></textarea>
  <select name="lang"><option>ru</option><option>en</option></select>
  <button type="submit">Отправить</button>
</form>

Блоки и семантика

div — блок, span — фрагмент в строке. Семантические теги описывают роль области. id уникален, class может повторяться.

<header><nav>…</nav></header>
<main>
  <section id="news" class="card">…</section>
  <article>…</article>
</main>
<footer>© 2026</footer>

CSS: основы и сравнение

CSS отвечает за внешний вид: цвета, шрифты, отступы, расположение. HTML — что показываем, CSS — как.

Три способа подключения

<!-- 1. Внешний файл (лучше всего) -->
<link rel="stylesheet" href="style.css">
<!-- 2. Блок в head -->
<style> p { color: red; } </style>
<!-- 3. Атрибут style (точечно) -->
<p style="color: red">Текст</p>

Селекторы

p { color: #333; }              /* по тегу */
.card { padding: 16px; }        /* по классу */
#menu { width: 200px; }         /* по id */
nav a { text-decoration: none; }/* потомок */
a:hover { color: tomato; }      /* состояние */
h1, h2 { margin: 0; }           /* несколько */
input[type="text"] { border: 1px solid #999; }

Текст, цвет, фон

body {
  font-family: Arial, sans-serif;
  font-size: 16px;
  color: #222;
  background: #f4f4f4;
  line-height: 1.5;
  text-align: center;
}
.btn { background: rgb(40, 120, 200); color: white; }

Блочная модель

Элемент состоит из содержимого, padding, border и margin.

* { box-sizing: border-box; }   /* ширина включает padding */
.box {
  width: 300px;
  padding: 10px 20px;           /* верх-низ, лево-право */
  border: 2px solid #333;
  border-radius: 8px;
  margin: 0 auto;               /* по центру */
}

Flexbox: ряд или колонка

.row {
  display: flex;
  gap: 12px;
  justify-content: space-between; /* по главной оси */
  align-items: center;            /* по поперечной */
  flex-wrap: wrap;
}

Grid: сетка

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

Адаптивность

@media (max-width: 600px) {
  .cards { grid-template-columns: 1fr; }
}

SQLite, модуль sqlite3 и основы SQL

SQLite — база данных в одном файле, без отдельного сервера. Модуль sqlite3 входит в стандартную библиотеку Python, устанавливать ничего не нужно.

Подключение и работа

import sqlite3

con = sqlite3.connect("shop.db")   # файл создастся сам
cur = con.cursor()
cur.execute("SELECT 1")
print(cur.fetchone())              # (1,)
con.commit()                       # сохранить изменения
con.close()

Получение результатов

cur.execute("SELECT id, name FROM users")
cur.fetchone()      # одна строка (или None)
cur.fetchmany(5)    # пять строк
cur.fetchall()      # список всех строк
for row in cur:     # построчно
    print(row)
cur.lastrowid       # id последней вставки
cur.rowcount        # сколько строк затронуто

Строки как словари

con.row_factory = sqlite3.Row
row = con.execute("SELECT * FROM users").fetchone()
row["name"]           # доступ по имени столбца
dict(row)             # в обычный словарь

Контекстный менеджер

with con: делает commit при успехе и rollback при ошибке, но соединение не закрывает.

with con:
    con.execute("INSERT INTO users(name) VALUES (?)", ("Аня",))
con.close()

CREATE TABLE

CREATE TABLE IF NOT EXISTS users (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    name    TEXT    NOT NULL,
    email   TEXT    UNIQUE,
    age     INTEGER CHECK (age >= 0),
    balance REAL    DEFAULT 0,
    created TEXT    DEFAULT CURRENT_TIMESTAMP
);
DROP TABLE IF EXISTS old_table;

Типы и ограничения

INTEGERцелые числа
REALдробные
TEXTстроки (даты — текстом ISO)
BLOBдвоичные данные
PRIMARY KEYуникальный идентификатор строки
NOT NULLзначение обязательно
UNIQUEбез повторов
DEFAULTзначение по умолчанию
FOREIGN KEYссылка на другую таблицу

INSERT: добавить

cur.execute("INSERT INTO users (name, age) VALUES (?, ?)", ("Аня", 20))
con.commit()
print(cur.lastrowid)   # 1

users = [("Боря", 31), ("Вика", 25)]
cur.executemany("INSERT INTO users (name, age) VALUES (?, ?)", users)
con.commit()

SELECT: выбрать

SELECT * FROM users;                       -- все столбцы
SELECT name, age FROM users WHERE age >= 21;
SELECT * FROM users WHERE name LIKE 'А%';  -- начинается с А
SELECT * FROM users ORDER BY age DESC LIMIT 3;
SELECT COUNT(*), AVG(age) FROM users;
SELECT age, COUNT(*) FROM users GROUP BY age;
SELECT * FROM users WHERE age IS NULL AND (name = 'Аня' OR id = 2);

UPDATE: изменить

Без WHERE изменятся все строки.

cur.execute("UPDATE users SET age = ? WHERE id = ?", (21, 1))
con.commit()
print(cur.rowcount)    # 1 — сколько строк обновлено

DELETE: удалить

Без WHERE удалится вся таблица построчно.

cur.execute("DELETE FROM users WHERE id = ?", (3,))
con.commit()

Скрипт из нескольких команд

con.executescript("""
    CREATE TABLE a (id INTEGER PRIMARY KEY);
    CREATE TABLE b (id INTEGER PRIMARY KEY);
""")

Плейсхолдеры

Плейсхолдер — метка (? или :имя) вместо значения в SQL-запросе. Значения передаются отдельно вторым аргументом.

Два вида

# позиционные ?
cur.execute("SELECT * FROM users WHERE name = ? AND age > ?", ("Аня", 18))
# именованные :name
cur.execute("SELECT * FROM users WHERE name = :n", {"n": "Аня"})
# один параметр — всё равно кортеж!
cur.execute("DELETE FROM users WHERE id = ?", (5,))

Опасно: f-строка вместо плейсхолдера

Ввод пользователя становится частью SQL-кода (SQL-инъекция).

name = "x' OR '1'='1"
cur.execute(f"SELECT * FROM users WHERE name = '{name}'")
# запрос: ... WHERE name = 'x' OR '1'='1'
# вернёт ВСЕХ пользователей

name = "x'; DROP TABLE users; --"   # ещё хуже в БД с несколькими командами

Правильно

cur.execute("SELECT * FROM users WHERE name = ?", (name,))
# драйвер передаёт name как данные, а не как код
# запрос ищет пользователя с именем ровно "x' OR '1'='1"

Зачем нужны плейсхолдеры

  • Безопасность. Защита от SQL-инъекций: данные не могут изменить смысл запроса.
  • Правильное экранирование. Кавычки в данных (О'Брайен) не ломают запрос.
  • Типы данных. Числа, None (станет NULL), строки передаются корректно без ручного форматирования.
  • Читаемость. Запрос и значения разделены, нет склейки строк.
  • Повторное использование. Один запрос с разными данными: executemany.

Ограничение: плейсхолдером можно заменить только значение. Имя таблицы или столбца подставить нельзя — их проверяйте по белому списку.

ALLOWED = {"users", "orders"}
if table in ALLOWED:
    cur.execute(f"SELECT * FROM {table}")

Проектирование БД: связи между таблицами

Таблицы связывают через внешний ключ (FOREIGN KEY) — столбец, хранящий id строки из другой таблицы. В SQLite проверку ключей нужно включить: PRAGMA foreign_keys = ON.

Один к одному (1:1)

Одному пользователю — один профиль. Столбец-ссылка делают UNIQUE.

CREATE TABLE users (
    id INTEGER PRIMARY KEY, login TEXT NOT NULL
);
CREATE TABLE profiles (
    id INTEGER PRIMARY KEY,
    user_id INTEGER UNIQUE NOT NULL,
    bio TEXT,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
SELECT u.login, p.bio
FROM users u JOIN profiles p ON p.user_id = u.id;

Один ко многим (1:N)

У автора много книг, у книги один автор. Ссылка лежит в таблице «многих».

CREATE TABLE authors (
    id INTEGER PRIMARY KEY, name TEXT NOT NULL
);
CREATE TABLE books (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    author_id INTEGER NOT NULL,
    FOREIGN KEY (author_id) REFERENCES authors(id)
);
SELECT a.name, COUNT(b.id) AS books
FROM authors a LEFT JOIN books b ON b.author_id = a.id
GROUP BY a.id;

Многие ко многим (M:N)

Студент ходит на много курсов, на курсе много студентов. Нужна связующая таблица с двумя внешними ключами.

CREATE TABLE students (id INTEGER PRIMARY KEY, name TEXT);
CREATE TABLE courses  (id INTEGER PRIMARY KEY, title TEXT);
CREATE TABLE enrollments (
    student_id INTEGER NOT NULL,
    course_id  INTEGER NOT NULL,
    PRIMARY KEY (student_id, course_id),
    FOREIGN KEY (student_id) REFERENCES students(id),
    FOREIGN KEY (course_id)  REFERENCES courses(id)
);
SELECT s.name, c.title
FROM enrollments e
JOIN students s ON s.id = e.student_id
JOIN courses  c ON c.id = e.course_id;

Каскадное удаление

FOREIGN KEY (author_id) REFERENCES authors(id)
    ON DELETE CASCADE   -- удалили автора — удалились его книги

Принципы проектирования

  • У каждой таблицы свой PRIMARY KEY.
  • Одна таблица — одна сущность (пользователи, заказы, товары).
  • Не дублируйте данные — храните ссылку на id.
  • Одно значение в ячейке, без списков через запятую.
  • Связь M:N всегда через третью таблицу.

Работа с БД: шаблон на Python и инструменты

Шаблон db.py (используется и в мини-проекте)

Один модуль отвечает за соединение, схему и простые функции запросов. Остальной код БД «не видит».

import sqlite3
from contextlib import closing
from pathlib import Path

DB_PATH = Path(__file__).with_name("app.db")
SCHEMA = """
CREATE TABLE IF NOT EXISTS tasks (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    owner TEXT    NOT NULL,
    title TEXT    NOT NULL,
    done  INTEGER NOT NULL DEFAULT 0
);
"""

def connect():
    con = sqlite3.connect(DB_PATH)
    con.row_factory = sqlite3.Row
    con.execute("PRAGMA foreign_keys = ON")
    return con

def init_db():
    with closing(connect()) as con, con:
        con.executescript(SCHEMA)

def query(sql, args=(), one=False):
    """SELECT: список строк или одна строка."""
    with closing(connect()) as con:
        rows = con.execute(sql, args).fetchall()
    return (rows[0] if rows else None) if one else rows

def execute(sql, args=()):
    """INSERT/UPDATE/DELETE с автосохранением. Возвращает id вставки."""
    with closing(connect()) as con, con:
        return con.execute(sql, args).lastrowid

DB Browser for SQLite

Бесплатная программа с интерфейсом для просмотра и правки .db-файлов (sqlitebrowser.org).

  1. Установите и откройте программу.
  2. Open Database → выберите файл app.db.
  3. Вкладка Database Structure: таблицы и столбцы, Create Table — создать таблицу мышью.
  4. Вкладка Browse Data: просмотр и правка строк.
  5. Вкладка Execute SQL: пишите запросы и запускайте (Ctrl+Enter).
  6. Изменения сохраняйте Write Changes (Ctrl+S).

Закройте программу или сохраните изменения, пока приложение пишет в тот же файл, иначе возможна блокировка базы.

SQLite Viewer для VS Code

Расширение показывает таблицы прямо в редакторе.

  1. В VS Code откройте Extensions (Ctrl+Shift+X).
  2. Найдите SQLite Viewer и нажмите Install.
  3. Щёлкните по файлу .db в проводнике — откроется просмотр таблиц.
  4. Выберите таблицу слева, чтобы увидеть строки; можно фильтровать и экспортировать в CSV.

Расширение подходит для просмотра, а сложные запросы удобнее в DB Browser.

Flask: основы

Flask — лёгкий веб-фреймворк. Принимает запрос от браузера, вызывает функцию-обработчик (view) и возвращает ответ.

Установка и запуск

pip install flask
python app.py
# или: flask --app app run --debug
# откройте http://127.0.0.1:5000

Приложение с декоратором

Декоратор @app.route связывает адрес (правило) с функцией.

from flask import Flask
app = Flask(__name__)

@app.route("/")
def index():
    return "Привет, мир!"

@app.route("/about")
def about():
    return "<h1>О нас</h1>"

if __name__ == "__main__":
    app.run(debug=True)

Без декораторов: add_url_rule

Тот же результат: функцию регистрируют вручную. Удобно, когда правила собираются в цикле.

def index():
    return "Привет, мир!"

app.add_url_rule("/", "index", index)
app.add_url_rule("/about", "about", lambda: "О нас")
# app.add_url_rule(правило, имя_эндпоинта, функция, methods=[...])

Добавление правил: параметры в адресе

@app.route("/user/<name>")
def user(name):                  # строка
    return f"Привет, {name}!"

@app.route("/post/<int:post_id>")
def post(post_id):               # целое число
    return f"Пост №{post_id}"
# конвертеры: string, int, float, path, uuid

Методы GET и POST

GET — получить страницу, POST — отправить данные формы.

from flask import request

@app.route("/hello", methods=["GET", "POST"])
def hello():
    if request.method == "POST":
        name = request.form["name"]        # поле формы
        return f"Привет, {name}!"
    return '<form method="post"><input name="name"><button>OK</button></form>'

# сокращения: @app.get("/x"), @app.post("/x")
# request.args.get("q")  — параметры ?q=...

Перенаправление

redirect отправляет браузер на другой URL, url_for строит адрес по имени функции (не ломается при смене правила).

from flask import redirect, url_for

@app.route("/old")
def old():
    return redirect(url_for("index"))     # на "/"

@app.route("/go/<int:n>")
def go(n):
    return redirect(url_for("post", post_id=n))
# redirect("https://example.com") — внешний адрес

Ошибки

from flask import abort

@app.route("/item/<int:i>")
def item(i):
    if i > 10:
        abort(404)
    return "ok"

@app.errorhandler(404)
def not_found(e):
    return "Страница не найдена", 404

Сессии

Данные пользователя между запросами хранятся в подписанной cookie. Нужен secret_key.

from flask import session

app.secret_key = "длинная-случайная-строка"

@app.route("/login", methods=["POST"])
def login():
    session["user"] = request.form["name"]
    return redirect(url_for("index"))

@app.route("/")
def index():
    return f"Вы: {session.get('user', 'гость')}"

@app.route("/logout")
def logout():
    session.pop("user", None)    # или session.clear()
    return redirect(url_for("index"))

Шаблоны Jinja2

HTML-файлы лежат в папке templates/. В них можно вставлять данные из Python.

from flask import render_template

@app.route("/")
def index():
    return render_template("index.html", title="Главная", items=["a", "b"])
<h1>{{ title }}</h1>
{% if items %}
  <ul>
  {% for x in items %}
    <li>{{ loop.index }}. {{ x|upper }}</li>
  {% endfor %}
  </ul>
{% else %}
  <p>Пусто</p>
{% endif %}

Наследование шаблонов

<!-- templates/base.html -->
<title>{% block title %}Сайт{% endblock %}</title>
<nav>…меню…</nav>
{% block content %}{% endblock %}

<!-- templates/page.html -->

Статика (CSS, картинки)

<link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
<img src="{{ url_for('static', filename='logo.png') }}">

Связка в стек и публикация

Как части работают вместе

Браузер  ──запрос GET /──────────►  Flask (Python, app.py)
 (HTML/CSS)                              │ маршрут → функция
                                         ▼
                                    db.py → SQLite (app.db)
                                         │ строки результата
                                         ▼
Браузер  ◄──HTML (render_template)── Jinja2 шаблон + данные
         ◄──CSS из /static───────────

Форма (POST) → Flask → INSERT/UPDATE/DELETE → redirect → новая страница (GET)
  • Фронтенд: HTML-шаблоны + CSS в браузере пользователя.
  • Бэкенд: Flask принимает запросы, проверяет данные, обращается к БД.
  • База данных: SQLite хранит данные в файле.

Доступ из локальной сети

Другие устройства в вашей Wi-Fi/LAN сети откроют сайт по IP вашего компьютера.

  1. Запустите на всех интерфейсах:
app.run(host="0.0.0.0", port=5000)
# или: flask --app app run --host=0.0.0.0
  1. Узнайте свой IP: ipconfig (Windows, «IPv4-адрес») или ip a / ifconfig (Linux, macOS).
  2. На другом устройстве откройте http://192.168.1.25:5000 (подставьте свой IP).
  3. Разрешите порт 5000 в брандмауэре, если соединение блокируется.

Не используйте debug=True с host="0.0.0.0" в сети, где вам не доверяют: отладчик позволяет выполнять код на сервере.

Публикация на PythonAnywhere

Хостинг, рассчитанный на Python; есть бесплатный тариф (условия проверьте на сайте).

  1. Зарегистрируйтесь на pythonanywhere.com.
  2. Вкладка Files: загрузите проект (или git clone в консоли Bash).
  3. В консоли: pip install --user flask (или создайте virtualenv и поставьте requirements.txt).
  4. Вкладка Web → Add a new web app → Flask, укажите путь к app.py.
  5. В WSGI-файле подключите приложение:
import sys
sys.path.insert(0, "/home/ИМЯ/todo")
from app import app as application
  1. Нажмите Reload. Сайт откроется по адресу ИМЯ.pythonanywhere.com.

Публикация через Git (Render, Railway и подобные)

  1. Загрузите проект на GitHub (с requirements.txt, без .venv).
  2. Создайте на хостинге Web Service и подключите репозиторий.
  3. Команда сборки: pip install -r requirements.txt.
  4. Команда запуска: gunicorn app:app.
  5. Добавьте переменную окружения SECRET_KEY.

Внимание: на многих облачных тарифах файловая система временная, и файл SQLite может обнулиться при перезапуске. Для постоянных данных нужен подключаемый диск или облачная СУБД (например, PostgreSQL). Условия тарифов смотрите на сайте хостинга.

Мини-проект: «Список задач»

Вход по имени (сессия), добавление, отметка и удаление задач. Используются: Flask, шаблоны, форма POST, redirect, SQLite с плейсхолдерами, HTML и CSS. Файл db.py — из шаблона выше.

app.py

import os
from flask import Flask, render_template, request, redirect, url_for, session
from db import init_db, query, execute

app = Flask(__name__)
app.secret_key = os.environ.get("SECRET_KEY", "dev-only-change-me")
init_db()

def current_user():
    return session.get("user")

@app.route("/")
def index():
    user = current_user()
    if not user:
        return redirect(url_for("login"))
    tasks = query("SELECT * FROM tasks WHERE owner = ? ORDER BY done, id DESC", (user,))
    return render_template("index.html", tasks=tasks)

@app.route("/login", methods=["GET", "POST"])
def login():
    if request.method == "POST":
        name = request.form.get("name", "").strip()
        if name:
            session["user"] = name
            return redirect(url_for("index"))
    return render_template("login.html")

@app.route("/logout")
def logout():
    session.clear()
    return redirect(url_for("login"))

@app.post("/add")
def add():
    title = request.form.get("title", "").strip()
    if current_user() and title:
        execute("INSERT INTO tasks (owner, title) VALUES (?, ?)", (current_user(), title))
    return redirect(url_for("index"))

@app.post("/toggle/<int:task_id>")
def toggle(task_id):
    execute("UPDATE tasks SET done = 1 - done WHERE id = ? AND owner = ?", (task_id, current_user()))
    return redirect(url_for("index"))

@app.post("/delete/<int:task_id>")
def delete(task_id):
    execute("DELETE FROM tasks WHERE id = ? AND owner = ?", (task_id, current_user()))
    return redirect(url_for("index"))

if __name__ == "__main__":
    app.run(debug=True)
