Типы данных

Тип определяет, какие значения хранятся и что с ними можно делать. Узнать тип: type(x), проверить: isinstance(x, int).

Основные типы

ТипПримерЧто этоИзменяемый
int42, -7Целое число, размер не ограниченнет
float3.14, 2e3Число с плавающей точкойнет
boolTrue, FalseЛогическое значениенет
str"привет"Строка (текст)нет
list[1, "a", 2.5]Упорядоченный списокда

Проверка типа

Python определяет тип по значению (динамическая типизация).

type(5)              # <class 'int'>
type("5")            # <class 'str'>
isinstance(2.5, float)  # True
isinstance(True, int)   # True

Приведение типов

Функции-конструкторы превращают значение в другой тип.

int("15")      # 15
int(3.9)       # 3 (отбрасывает дробную часть)
float("2.5")   # 2.5
str(100)       # '100'
bool(0)        # False
list("abc")    # ['a', 'b', 'c']

Арифметика чисел

/ всегда даёт float, // — целое деление.

7 / 2      # 3.5
7 // 2     # 3
7 % 2      # 1 (остаток)
2 ** 10    # 1024
divmod(7, 2)  # (3, 1)
abs(-4)    # 4
round(2.675, 1)  # 2.7

Точность float

Дробные числа хранятся приблизительно. Для сравнения используйте round или math.isclose.

0.1 + 0.2             # 0.30000000000000004
round(0.1 + 0.2, 2)   # 0.3
2 ** 100              # int без ограничений

Изменяемые и неизменяемые

Изменяемые (list, dict) правятся «на месте». Неизменяемые (int, str, tuple) создаются заново.

a = [1, 2]; a.append(3)   # a → [1, 2, 3]
t = (1, 2)
t[0] = 9    # TypeError

Литералы и разделители

1_000_000    # 1000000 (подчёркивания для чтения)
0xFF         # 255 (16-ричное)
0b101        # 5 (двоичное)
0o17         # 15 (восьмеричное)
1.5e-3       # 0.0015

Переменные

Переменная — это имя, привязанное к объекту в памяти. Оператор = не копирует значение, а связывает имя с объектом.

Создание

Объявлять тип заранее не нужно. Имя можно привязать к другому типу.

age = 25          # int
name = "Анна"     # str
age = "двадцать"  # теперь str
del age           # удалить имя

Правила имён

Допустимы буквы, цифры и _. Нельзя начинать с цифры, использовать пробелы, дефисы и ключевые слова. Регистр важен.

user_1 = 1     # верно
_tmp = 2       # верно
1user = 3      # SyntaxError
my-var = 4     # SyntaxError
class = 5      # SyntaxError
Age != age     # разные имена

Стиль имён (PEP 8)

Договорённости, которые не проверяет интерпретатор, но ждут от кода.

user_name = "ann"   # snake_case: переменные
MAX_SIZE = 100      # КОНСТАНТЫ
_hidden = 1         # «внутреннее» имя
__x = 2             # защита имени в классе

Ключевые слова

Зарезервированы языком, использовать как имена нельзя. Полный список:

import keyword
print(keyword.kwlist)
# False None True and as assert async await
# break class continue def del elif else except
# finally for from global if import in is
# lambda nonlocal not or pass raise return
# try while with yield

Присваивание

Несколько имён одним оператором, обмен значений без временной переменной.

a, b = 1, 2        # два значения сразу
x = y = 0          # одно значение двум именам
a, b = b, a        # обмен: a=2, b=1
first, *rest = [1, 2, 3]   # 1 и [2, 3]

Составное присваивание

Короткая запись «изменить и сохранить».

n = 10
n += 5    # 15
n -= 3    # 12
n *= 2    # 24
n //= 5   # 4
n **= 2   # 16
s = "a"; s += "b"   # 'ab'

Имя — это ссылка

Два имени могут указывать на один изменяемый объект. Для независимой копии используйте .copy().

a = [1, 2]
b = a
b.append(3)
print(a)     # [1, 2, 3] — a тоже изменился
c = a.copy()   # независимая копия
id(a) == id(b) # True: один объект

Ввод и вывод

input() всегда возвращает строку. print() принимает sep и end.

name = input("Имя: ")
print("Привет,", name)
print(1, 2, 3, sep="-")      # 1-2-3
print("a", end="")           # без переноса

Работа со строками

Строка (str) — неизменяемая упорядоченная последовательность символов.

Создание и экранирование

a = 'одинарные'
b = "двойные"
c = """несколько
строк"""
d = "Он сказал: \"привет\"\n"   # \n перенос
e = r"C:\new\file"   # raw: \ как есть
"Py" "thon"          # 'Python' (склейка)

Индексы и срезы

Индексация с 0, с конца — отрицательные. Срез [старт:стоп:шаг], стоп не включается.

s = "Python"
s[0]       # 'P'
s[-1]      # 'n'
s[1:4]     # 'yth'
s[:2]      # 'Py'
s[::2]     # 'Pto'
s[::-1]    # 'nohtyP' (разворот)

Операции

"ab" + "cd"     # 'abcd'
"ab" * 3        # 'ababab'
len("Привет")   # 6
"th" in "Python"   # True
"a" < "b"        # True (по коду символа)
ord("a"), chr(98)  # (97, 'b')

split — разделить строку

Без аргумента режет по пробелам, с аргументом — по указанному разделителю.

"a b  c".split()       # ['a', 'b', 'c']
"1,2,3".split(",")     # ['1', '2', '3']
"один два".split(" ")  # ['один', 'два']

Поиск и замена

s = "banana"
s.find("an")      # 1 (или -1, если нет)
s.count("a")      # 3
s.replace("a", "o")   # 'bonono'

Проверки содержимого

"123".isdigit()    # True
"abc".isalpha()    # True
"ab1".isalnum()    # True
"abc".islower()    # True
"  ".isspace()     # True

Вложенность и лаконичные конструкции

Python позволяет подставлять вызов функции прямо в аргумент другой. Читается изнутри наружу.

Ввод числа в одну строку

# длинно:
s = input()
n = int(s)
# коротко:
n = int(input())
x = float(input("Вес: "))

Несколько чисел с одной строки

# ввод: 3 5
a, b = map(int, input().split())
print(a + b)    # 8
# ввод: 4 1 9
nums = list(map(int, input().split()))   # [4, 1, 9]

Вложенные вызовы

len(str(2 ** 100))      # 31 — цифр в числе
sum(map(int, "12345"))  # 15 — сумма цифр
max(len(w) for w in ["a", "abc"])  # 3
abs(int(input()))       # модуль введённого

Встроенные функции вместо кода

nums = [4, 1, 9]
sum(nums)        # 14
min(nums)        # 1
max(nums)        # 9
sorted(nums)     # [1, 4, 9]
len(nums)        # 3
sum(nums) / len(nums)   # среднее 4.666…

Компактный вывод

nums = [1, 2, 3]
print(*nums)                # 1 2 3
print(*nums, sep=", ")      # 1, 2, 3
print("Сумма:", sum(nums))  # Сумма: 6

Цепочка сравнений

x = 5
0 < x < 10          # True
a = b = c = 0       # одно значение трём именам
name = input() or "аноним"   # если пусто → 'аноним'

Распаковка

x, y = (10, 20)
h, m = map(int, "12:30".split(":"))   # 12, 30
first, *mid, last = [1, 2, 3, 4]      # 1, [2, 3], 4
_, b = "a b".split()                  # _ — не нужно

Принцип вложенности структур

matrix = [[1, 2, 3], [4, 5, 6]]
matrix[1][2]            # 6

user = {"name": "Аня", "langs": ["ru", "en"], "addr": {"city": "Москва"}}
user["langs"][0]        # 'ru'
user["addr"]["city"]    # 'Москва'
user.get("age", 0)      # 0 — безопасно, если ключа нет

Знакомство

Сумма двух чисел

3 + 5 = 8

Показать решение

print(a, "+", b, "=", a + b)

Без int() была бы ошибка — input() возвращает строку, а склеивать строки через + можно, но тогда получится "35", а не 8.

Обмен значений

Есть a = 5 и b = 10. Поменяйте их значения местами двумя способами: классическим (через временную переменную) и «питоновским» (в одну строку).

a, b = 5, 10
a, b = b, a

ЗАДАЧА 9

Половина и остаток

Дано число n = 17. Выведите: сколько раз 5 помещается в него целиком (целое деление) и какой остаток (деление по модулю). Используйте divmod() или // и %.

Показать решение 
n = 17

# способ 1: обычными операторами
print("Целых пятёрок:", n // 5)   # 3
print("Остаток:", n % 5)          # 2

# способ 2: через divmod
quotient, remainder = divmod(n, 5)
print("Целых:", quotient)
print("Остаток:", remainder)
ЗАДАЧА 10

Из строки в число

Есть строка price = "149.90". Преобразуйте её в число, прибавьте 10, округлите до 2 знаков после запятой и выведите результат. Каким типом будет итоговое значение?

Показать решение 
price = "149.90"
price = float(price)         # 149.9
total = price + 10           # 159.9
total = round(total, 2)      # 159.9

print(total)                 # 159.9
print(type(total))           # <class 'float'>

Итог — float, потому что исходная строка содержала точку. Если бы в строке было "149", то после int() получился бы int.

ЗАДАЧА 14

Частота буквы

Попросите пользователя ввести текст и букву. Посчитайте, сколько раз эта буква встречается в тексте. Например, для текста банан и буквы а должно получиться:

Показать решение

ЗАДАЧА 16

Имя файла

Дано: path = "photo_2026_10_08.jpg". Выведите отдельно имя файла без расширения и само расширение.

Показать решение 
path = "photo_2026_10_08.jpg"

name, ext = path.split(".")
print("Имя:", name)         # photo_2026_10_08
print("Расширение:", ext)   # jpg

Метод split вернёт список; распаковка двумя именами сработает, только если в строке ровно одна точка. Если точек несколько, лучше path.rsplit(".", 1) — режет по последней точке.

ЗАДАЧА 17

Приветствие по имени

Попросите пользователя ввести имя. Затем выведите: Привет, ИМЯ! В твоём имени N букв. где N — количество символов.

Показать решение 
name = input("Как тебя зовут? ")

print("Привет, " + name + "! В твоём имени " + str(len(name)) + " букв.")

len(name) даёт число, а str(...) превращает его в строку — иначе Python не сможет приклеить число к тексту через +.

Совет: если вложенный вызов стал трудно читать, разбейте его на два-три шага с понятными именами переменных.
