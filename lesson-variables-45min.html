Разминка: задача от турфирмы

Понять, зачем нужны переменные

Директор турфирмы просит посчитать стоимость поездки. В группе 18 человек, билет стоит 1990 рублей. Пишем программу:

print(1990 * 18)
Запуск
35820

Всё работает! Но завтра придёт другая группа: 25 туристов по 1450 рублей. Что придётся сделать с программой?

Обсуждение

Подумай 30 секунд и ответь

  1. Сколько раз нужно переписать число 1990 в коде?
  2. А если таких групп 18 каждый день?
  3. А если бухгалтер сам не умеет программировать?
Показать ответ

Придётся каждый раз менять код: числа 1990 и 18 разбросаны внутри программы. Если бухгалтер их случайно заденет — программа сломается. И делать это 18 раз в день — очень долго.

Вывод: данные нужно вынести из кода в переменные. А чтобы бухгалтеру не пришлось ничего менять — пусть программа сама спрашивает данные через input().

Переменные: первая ячейка памяти

Научиться создавать переменные и менять их значения

Переменная — это коробка с наклейкой-именем. Внутри лежит значение. Наклейка помогает программе потом найти эту коробку.

# Создаём переменные ticket_price = 1990 amount_adults = 18 # Считаем и печатаем total = ticket_price * amount_adults print(total)
Запуск
35820

Три переменные — три коробки: ticket_price, amount_adults, total. Числа лежат внутри переменных, а не спрятаны в коде.

Значение можно менять в любой момент:

age = 1 print('Было:', age) age = age + 1 # взять старое, прибавить, положить обратно print('Стало:', age)
Запуск
Было: 1
Стало: 2

Три типа данных: int, float, str

Различать числа и строки

В переменных могут лежать значения разного типа. На старте знакомимся с тремя:

int — 42, 1990
float — 3.14, 0.15
str — 'Васечкин', "Тула"

Разница видна сразу: числа пишутся без кавычек, строки — в кавычках. От типа зависит, что можно с ними делать.

# Числа — можно считать ticket_price = 1990 # int discount = 0.15 # float total = ticket_price * 18 print(total) # Строка — можно соединять с другими строками guide = 'Васечкин' print('Экскурсовод:', guide)

Определи тип каждого значения — это int, float или str?

  1. 42
  2. "42"
  3. 3.99
  4. 'Москва'
  5. 0.5
Показать ответы 
42        → int   (число без кавычек)
"42"      → str   (в кавычках — уже строка!)
3.99      → float (есть точка)
'Москва'  → str   (в кавычках)
0.5       → float

Обрати внимание на ловушку: 42 и "42" — совсем разные типы. Первое можно умножать, второе — только соединять с другими строками.

Функция input(): программа спрашивает данные

Научиться считывать данные с клавиатуры

Чтобы бухгалтеру не пришлось менять код, программа сама задаст вопросы через input().

guide = input('Введите фамилию экскурсовода: ') city = input('Введите город: ') print('Директор филиала в г.', city, '-', guide)

Вот что увидит пользователь при запуске:

Диалог с программой
Введите фамилию экскурсовода: Солнцев
Введите город: Тула
Директор филиала в г. Тула - Солнцев

Что происходит по шагам:

  1. Python встречает команду input(...).
  2. Показывает текст в скобках.
  3. Ждёт, пока пользователь напечатает ответ и нажмёт Enter.
  4. Помещает ответ в переменную guide.

int() и ловушка типов

Превращать строку из input() в число

А теперь сюрприз: input() всегда возвращает строку. Даже если пользователь ввёл число. Посмотрим, что будет, если попробовать его сложить с числом:

add_services = input('Стоимость доп. услуг: ') total = 2500 + add_services print('Итого:', total)
Ошибка!
Стоимость доп. услуг: 300

unsupported operand type(s) for Add: 'int' and 'str'
Что случилось? Python не умеет складывать число 2500 со строкой "300". Ответ пользователя — это строка, её нужно превратить в число. unsupported operand type(s) for Add: 'int' and 'str'

Спасает функция int() — она превращает строку в целое число.

add_services = int( input('Стоимость доп. услуг: ') ) total = 2500 + add_services print('Итого:', total)
Работает
Стоимость доп. услуг: 300
Итого: 2800

  1. Что такое переменная и зачем она нужна?
  2. Какой тип данных возвращает функция input()?

Показать ответы

Задание 2 · Базовое

Измени значение

Создай переменную score = 0. Затем трижды измени её значение: сначала прибавь 10, потом отними 3, затем прибавь 25. Выведи итог на экран.

Показать решение 
score = 0
score += 10   # стало 10
score -= 3    # стало 7
score += 25   # стало 32

print(score)  # 32

Короткая запись += делает то же, что score = score + 10, но читается проще.

Задание 3 · Среднее

Обмен значений

Есть a = 5 и b = 10. Поменяй их значения местами двумя способами: через временную переменную и в одну строку. Выведи результат до и после обмена.

Показать решение 
a = 5
b = 10
print("До обмена:", a, b)

# Способ 1: через временную переменную
temp = a
a = b
b = temp
print("После 1:", a, b)

# Способ 2: питоновский
a = 5
b = 10
a, b = b, a
print("После 2:", a, b)

Второй способ работает, потому что Python сначала вычисляет правую часть (b, a = кортеж), а только потом присваивает.

Часть 2. Правила имён

Задание 4 · Найди ошибки

Какие имена нельзя использовать?

Проверь каждую строку — есть ли здесь ошибка? Если да, в чём?

1) my_name = "Аня"
2) 2name = "Боря"
3) user-age = 12
4) print = "Привет"
5) _score = 100
6) МойДом = "Москва"
Показать решение 
1) my_name = "Аня"     # ✅ правильно
2) 2name = "Боря"      # ❌ начинается с цифры
3) user-age = 12       # ❌ дефис запрещён, только _
4) print = "Привет"    # ❌ print — зарезервированная команда
5) _score = 100        # ✅ правильно
6) МойДом = "Москва"   # ✅ формально можно, но так не принято
                       #    в Python пишут по-английски и в нижнем регистре

Правила:

  • Имя состоит из букв, цифр и _.
  • Первым символом — буква или _.
  • Нельзя занимать зарезервированные слова (print, input, int, for…).
  • Стиль: английские слова в нижнем регистре, через _: user_age, а не UserAge.

Часть 3. Типы данных

Задание 6 · Определи тип

Что за тип данных?

Определи тип каждого значения: int, float или str?

1) 42
2) 3.14
3) "42"
4) "Москва"
5) 0.5
6) 100
7) "3.14"
8) -7
Показать решение 
1) 42        → int   (целое без кавычек)
2) 3.14      → float (дробь без кавычек)
3) "42"      → str   (число в кавычках — это строка!)
4) "Москва"  → str
5) 0.5       → float
6) 100       → int
7) "3.14"    → str   (снова кавычки решают)

Правило: кавычки превращают что угодно в строку. 42 — это число, а "42" — уже текст.

Задание 7 · Числа и арифметика

Калькулятор с переменными

Создай переменные a = 7 и b = 3. Выведи результаты четырёх операций: сумма, разность, произведение, целочисленное деление. Используй print() с подписями.

Показать решение 
a = 7
b = 3

print("Сумма:", a + b)          # 10
print("Разность:", a - b)       # 4
print("Произведение:", a * b)   # 21
print("Целое деление:", a // b) # 2

Обрати внимание: a / b дало бы 2.333... (float), а a // b — только целую часть.

Часть 4. input() и int()

Задание 8 · Ввод данных

Анкета

Напиши программу, которая спрашивает имя и город пользователя через input(), а затем выводит приветствие: Привет, Аня! Как дела в Москве?

Задание 9 · Числа

Сумма двух чисел

Попроси пользователя ввести два числа и выведи их сумму. Не забудь про int() — иначе программа сложит строки, а не числа.

Показать решение 
a = int(input("Первое число: "))
b = int(input("Второе число: "))

total = a + b
print("Сумма:", total)

Ловушка: без int() программа получила бы "35" вместо 8 при вводе 3 и 5, потому что строки «складываются» встык.

Задание 10 · Итоговое

Возраст через 5 лет

Программа спрашивает у пользователя имя и текущий возраст, а затем выводит: Аня, через 5 лет тебе будет 17 лет. Используй input(), int() и переменные.

Показать решение 
name = input("Как тебя зовут? ")
age = int(input("Сколько тебе лет? "))

future_age = age + 5
print(name + ", через 5 лет тебе будет " + str(future_age) + " лет")

Два важных момента:

  • int(input(...)) — превращаем введённый текст в число, чтобы прибавить 5.
  • str(future_age) — превращаем результат обратно в строку, чтобы приклеить к тексту через +.

Альтернатива без str() — использовать print с запятыми:

print(name + ", через 5 лет тебе будет", future_age, "лет")
